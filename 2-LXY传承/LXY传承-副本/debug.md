公式推导（为什么 C = 50 − err）
车摆正时，中线实际在雷达坐标系里的位置就是标定值 C（不管它是不是 50）：


err   = 50 − x实际          （模式0: err = -((y-b)/k - 50) = 50 - x）
x实际 = C                   （车摆正时）
──────→  C = 50 − err
车摆正时串口显示	结论
ERROR ≈ 0	标定值就是 50，不用改（原车是这样标定的）
ERROR ≈ −30	实际 C = 50 − (−30) = 80 → 三处 50 改成 80
ERROR ≈ +20	实际 C = 50 − 20 = 30 → 三处 50 改成 30
验证一步（顺带验证方向）
标定完把车故意左移 50mm再测：err 应该变 ≈ −50（车左移 → 中线看起来偏右 → x 变大 → err 变负）。右移 50mm → err ≈ +50。方向对不上说明哪一步摆车摆错了，不影响 C 的公式本身。


车左移 50mm:  err ≈ −50     ← 中线偏右, x_实际 = C+50, err = 50-(C+50) = -50
车右移 50mm:  err ≈ +50
