# 蓝牙调参说明书

> 适用工程: `LXY传承-副本`（STM32F407VET6 @168MHz）
> 代码: [HARDWARE/hc-05/ble_tune.c](HARDWARE/hc-05/ble_tune.c) / [ble_tune.h](HARDWARE/hc-05/ble_tune.h)，设计原理见 [蓝牙实时调参方案.md](蓝牙实时调参方案.md)
> 前置：先按 [硬件测试说明书.md](硬件测试说明书.md) 测试③把蓝牙链路打通。
> **前提条件：main.c 里 `HW_TEST_SELECT` 必须是 0（正常循线模式）**，调参功能只在循线模式下工作。

---

## 1. 这是什么：两条数据流

```
【调参】手机/电脑 → HC-05 → USART6 → 每圈解析 → 直接改参数    (文本命令, 车跑动中实时生效)
【遥测】控制循环每帧 → USART6 → HC-05 → VOFA+ 波形组件        (二进制, 7通道实时曲线)
```

调参改的是**控制参数**（舵机 PD、电机 PI、几何补偿），不是代码——改完立刻生效、断电丢失（恢复出厂值=重烧固件或按 §8 表逐条发回去）。免烧录、免拖线，可以在车**跑动时**连续调。

---

## 2. 快速上手（5 分钟）

1. 手机/电脑连上 HC-05（配对码 `1234`，见硬件测试说明书 §5.2 的路径 A/B）。
2. VOFA+ 新建连接：串口 → 选蓝牙 COM 号 → 波特率 9600 → 数据引擎先选 **RawData**。
3. 发送面板发 `get`（记得勾"发送新行"）→ 应收到 16 行参数回显，第一行 `kp=35`。链路通了。
4. 发 `kp 35` → 回 `OK kp=35`。参数已改（波形里 ch2 会变）。
5. 把数据引擎切成**二进制引擎**（FireWater，见 §4）→ 拖一个波形组件 → 出 7 通道曲线（ch1 舵机 PWM 在 1360~1800 间跳动）。全部打通。

> 回显规则：`OK 名字=值`（成功）/ `ERR fmt`（格式错）/ `ERR range`（超范围，**不写值**）/ `ERR name`（没有这个命令）。

## 3. 命令速查表（16 条 + get）

格式：`命令 整数` 或 `命令:整数`（空格/冒号都认），每条以**换行**结尾。

| 命令 | 改的参数 | 发送值范围 | 实际写入 = 发送值÷10^scale | 出厂发送值 |
|---|---|---|---|---|
| `kp` | Servo_pd.kp（直道 P） | 0~1000 | ÷1000 | 35 → 0.035 |
| `kp2` | Servo_pd.kp_2（大转弯 P） | 0~1000 | ÷1000 | 40 → 0.040 |
| `kp3` | Servo_pd.kp_3（小转弯 P） | 0~1000 | ÷1000 | 40 → 0.040 ⚠️ |
| `kd` | Servo_pd.kd（直道 D） | 0~1000 | ÷1000 | 75 → 0.075 |
| `kd2` | Servo_pd.kd_2（大转弯 D） | 0~1000 | ÷1000 | 22 → 0.022 |
| `kd3` | Servo_pd.kd_3（小转弯 D） | 0~1000 | ÷1000 | 20 → 0.020 |
| `sp_kp` | Speed_pid.kp（速度环 P） | 0~5000 | ÷100 | 850 → 8.5 |
| `sp_ki` | Speed_pid.ki（速度环 I） | 0~5000 | ÷1000 | 505 → 0.505 |
| `spd` | Speed_mubiao（目标速度） | 0~50 | ÷1 | 17 |
| `disr` | BLUE_DIS_RIGHT（右侧宽度补偿） | 0~200 | ÷1 | 27 |
| `disl` | BLUE_DIS_LEFT（左侧宽度补偿） | 0~200 | ÷1 | 50 |
| `yr` | BLUE_Y_RIGHT（右转目标 Y） | 0~2000 | ÷1 | 1200 |
| `yl` | BLUE_Y_LEFT（左转目标 Y） | 0~2000 | ÷1 | 1350 |
| `ystra` | BLUE_Y_STRA（直道固定目标 Y） | 0~2000 | ÷1 | 750 |
| `ysel` | BLUE_Y_STRA_SEL（直道模式选择） | **0~1** | ÷1 | 0（0=用中线末点，1=用 ystra 固定值） |
| `angle` | BLUE_ANGLE_LEFT_RIGHT（左右边界扫描范围） | 0~180 | ÷1 | 90 |
| `get` | 回发全部 16 行当前值 | — | — | — |

⚠️ `kp3` 出厂 0.0395 在千分位分辨率下表达不了：`get` 显示 40，发 `kp3 40` 会真写成 0.040。误差 0.0005 对控制无感，按 40 处理即可。

⚠️ `get` 回 16 行 ≈ 240ms 期间主循环停摆（车按旧参数惯性跑），**建议停车时用**。

**钳位规则**：超范围一律 `ERR range` 且**不写值**（跑车时手滑发 `kp 5000` 不会炸）。参数只在发送值范围内可调，想扩大范围改 ble_tune.c 参数表。

## 4. VOFA+ 配置详解

### 4.1 连接与数据引擎

- 串口：9600, 8N1，选蓝牙对应的 COM 口。
- **文本阶段用 RawData 引擎**：能看到 `OK/ERR/get` 回显。
- **波形阶段切二进制引擎**：名字以**实测为准**——VOFA+ 官方叫 **FireWater**（N 个 float32 小端 + 帧尾 `00 00 80 7F`），网上大量博客把 FireWater/JustFloat 写反。哪个引擎一选就自动出 7 通道波形，哪个就是对的。

### 4.2 波形组件

- 选"波形"组件拖入，通道数选 7（或自动识别），横轴时间。
- 通道含义见 §5。

### 4.3 滑块控件（高级用法）

- VOFA+ 滑块默认发 `kp:45` 这种**冒号**格式——本解析器兼容，直接用。
- 滑块范围按**发送值**配（kp 建议 0~100，对应 0~0.100）。
- 发送面板手动输入时勾选"发送新行"（带 `\r\n`，解析器兼容）。

## 5. 遥测 7 通道表

每帧雷达处理完发一帧，7 通道 + 帧尾 = 32 字节（9600 下约 33ms/帧，雷达帧约 78ms，带宽安全）。

| ch | 内容 | 看什么 |
|---|---|---|
| 0 | 误差 err | 震荡/收敛；理想是过弯快速归零 |
| 1 | 舵机 PWM | 1360~1800。**顶到 1360/1800 = 饱和**，加大 kp 无意义 |
| 2 | 当前 kp | 确认参数真的改了 |
| 3 | 当前 kd | 同上 |
| 4 | pid 模式 0~9 | 当前走的模式（0 直道 / 1,2 小弯 / 3,4 大弯 / 5 垂线 / 6,7 均值 / 8,9 中弯） |
| 5 | 当前速度 Speed_now | 速度环响应快慢 |
| 6 | 目标速度 Speed_mubiao | 与 ch5 对比看跟踪 |

**口径提醒**：
- 直道中位 PWM 约 **1560**（代码里 `servo_midpwm = 156.5` 是 float，传给 uint16_t 参数时被截断成 156，内部 ×10 = 1560；不是 1565）。
- 强制转弯帧（main.c 直接 `Servo_ChangePwm(1360/1800)`）和首帧直道时，ch1 显示的是**上一帧的 PD 输出值**，不代表那一刻的物理 PWM——看波形时知道有这两种特殊情况即可。

## 6. 调参经验与操作顺序

1. **安全起步**：先 `spd 10` 低速跑，调稳了再提速。
2. **一次只改一个参数**，改完跑一圈看波形再决定下一步；用 `get` 随时记录当前整组参数（截图保存）。
3. **判读口诀**：
   - 直道左右画龙（蛇形）→ 调 `kp`（大）和 `kd`（大）
   - 大弯过冲/切内 → 调 `kp2`/`kd2`
   - 小弯贴边/刮线 → 调 `kp3`/`kd3`
   - 起步猛顿一下 → 降 `sp_ki`；提速上不去 → 加 `sp_ki`
   - ch1 常顶 1360/1800 → 舵机已饱和，加 kp 没用，先看机械/几何参数（`yr`/`yl`/`disr`/`disl`/`angle`）
4. **几何参数**只在确认模式走对（ch4）后再动：`yr/yl` 是转弯的目标 Y 坐标，`disr/disl` 是小转弯的边界补偿系数。
5. 曲线判读：ch0 err 快速回零+不震荡 = P/D 合适；ch5 跟 ch6 越紧 = 速度环越好。
6. 调好一组后**记录到文件**，防止断电丢失。

## 7. 常见问题 FAQ

| 问题 | 原因/处理 |
|---|---|
| 收不到任何波形 | ①没连接（HC-05 STATE 灯）②引擎选错（切 FireWater）③波特率不是 9600 |
| 发命令没回显 | ①没勾"发送新行"（按行解析）②引擎在二进制模式（切回 RawData 看文本）③未连接（未连接时不回发） |
| `ERR fmt` | 格式错：没有数字、没加分隔符。例：`kp`（无值）、`kpabc` |
| `ERR range` | 值超范围（见 §3 表），参数没被写 |
| `ERR name` | 命令名不在表里（注意是 `sp_kp` 不是 `skp`） |
| 发命令后像"卡住"再也不回 | 尾巴缓冲里残留半行：多发一个**回车（空行）**即可自愈 |
| 断开重连后 | 自动恢复：STATE 脚检测到连接后遥测自动继续，无需复位 |
| 想恢复出厂参数 | 按 §8 表逐条发回去，或直接重烧固件 |
| 调参时车抽动一下 | 正常：改的是 PID 系数不是状态；若在弯里猛抖，可能你把 kp/kd 改太极端，改回来即可 |
| 波形卡顿/掉帧 | 蓝牙 9600 带宽有限（33ms/帧遥测），属正常；高频数据走 USART3 有线 115200 |
| 车没连蓝牙能跑吗 | 能，未连接时调参模块零发送零阻塞，与没有此功能完全一样 |
