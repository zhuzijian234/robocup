# M10P代码架构

## 主链路

`DMA中断 → 字节队列 → M10P_Poll → M10P_Feed → Acquire → Build → 几何/PD → Radar_Observe → Release`。

TIM5独立运行10ms速度环，检查观测许可、新鲜度和故障代次后才输出电机PWM。

| 模块 | 职责 |
| --- | --- |
| m10p_config.h | 协议、点云容量、安装角、感知门限和车辆包络 |
| DMA.h/.c | 循环DMA、字节队列、接收时间戳和故障恢复 |
| m10p.h/.c | 160字节协议解析、整圈检查和双缓冲所有权 |
| m10p_vehicle.h/.c | 有界取块、工作点云、前方盲区/近障检查与限速 |
| LEIDA_DATA.h/.c | 当前使用的坐标转换、边界、中线、断点、前方墙面和宽度计算 |
| USER/main.c | 初始化、转向决策、有效观测提交和扫描归还 |
| timer.h/.c | 驱动许可与速度PI最终仲裁 |
| hc-05/ | 蓝牙调参、V2遥测和M10P健康统计 |

## 已直接删除

旧LD14P的47字节解析器、原始点云数组、旧筛选与自动校准函数、预留HANDLE12/13、无用文本打印函数、旧CRC8校验入口和旧解析计数均已删除，不再保留大段 `#if 0`。

旧雷达PWM源文件和头文件已删除，Keil工程及选项、两个EIDE入口的文件与包含路径同步清理；预留TIM14初始化和无引用的主程序变量也已删除。旧协议专用测试一并移除，当前M10P协议测试独立保留。

蓝牙 `radar` 命令直接显示M10P包数、不连续、拒收和溢出计数。V2 DETAIL原LD14P字段保持布局并填零，M10P完整统计仍由type 7提供。硬件测试模式、共享几何和厂商外设库保留。

## 验证

运行 `python test/verify_m10p.py`：覆盖M10P解析、DMA、几何、控制、遥测，核对三个工程入口并执行ARM构建；链接符号检查防止旧入口被意外带回。

几何/控制基础回归现为50项；原有239项旧LD14P协议检查随旧实现删除。M10P解析7751项、几何72236项和其余控制/DMA/遥测测试继续执行。固件摘要与内存占用见《M10P移植交付说明.md》。
