## 0.5 赛道模型（必读）

| 项 | 值（✅ = 已确认） | 对算法的影响 |
|---|---|---|
| 边界 | ✅ **直径 20cm 的铝箔管**，连续铺设 | 高度只有 20cm |
| 材质 | 金属铝箔 → 近镜面反射 | 掠射角可能把能量反射走 → 远侧边界偶发丢点；`high_reflect` 计数会升（固件不因该标志丢点，只计数） |
| 雷达高度 | ✅ **出光口离地 ≤ 20cm** | 低于管高 → 看得见管子。静止实测 `left/right=121`（满扇区）已印证 ✓ |
| 通道 | ✅ **50cm = 管内边到内边** | 车宽 26cm → **单侧余量 12cm** ✓ 现有几何参数可用，不需要重定标 |
| 通道内 | ✅ **锥桶贴一侧放**，另一侧留出 ≥50cm 通行 | 绕障简化成**单向推**；且锥桶会自己进入边界数组 → 现有中线逻辑**可能已经自动绕开**，见下 |

### 推论

1. **边界是连续管** ⇒ 只要看得见，`left/right_bins` 应接近满值。静止实测 `left=121 right=121`（满扇区）**印证雷达确实看得见管子**。所以跑动中出现的 `left_bins=0` / `clearance_mm=10000`，更可能是**已经撞出赛道、进入空旷区**，而不是判据太严。
2. **扫描面高度门槛从 30cm 降到 20cm**。这是唯一"改代码也没用"的硬件前提。
3. **`paodao_distance` 实测在 494~750mm 之间摆动**：低端 494 ≈ 50cm 通道 ✓；高端 600~750 对应"有锥桶处管子外扩"的正常设计 ✓ 两者自洽。
4. **通道内锥桶会污染中线估计**：`HANDLE4` 按对称角度左右配对，会把"一侧管子 + 另一侧锥桶"配成一对 → 中线偏移 → 转向被带偏。而且 `M10P_clearance_mm` **只做诊断、不参与转向**。

### 绕障方案（**暂不实现**，按 D1~D4 优先）

> **状态：设计已冻结，等 D1~D4 跑完再决定要不要做。**

#### 先看"为什么可能不需要"

锥桶是**贴着一侧管子放**、另一侧保证 ≥50cm 通行的。这意味着：

- 锥桶本身就是一个实体回波，会被 `HANDLE6/HANDLE7` 当成**那一侧的边界点**收进去；
- `HANDLE4` 按对称角度配对时，锥桶所在角度上"左=锥桶、右=管子"，**中点正好落在可通行区的中间** ✓
- 所以**现有的"左右配对求中点"逻辑本身就会绕开贴边锥桶**，不需要额外功能。

锥桶张角不大（20cm 宽：1m 处约 11°、2m 处约 5.7°），会被 `HANDLE4` 的多角度平均摊薄，残留偏差约几毫米到一两厘米——在 12cm 余量里可以接受。

**什么时候才真需要绕障**（出现这些现象再做）：
- 锥桶把对侧管子挡住，导致某个角度**配不上对** → `CENTER_cnt` 下降、中线跳变
- 锥桶比预期更靠中间（不是贴边）
- 直道上明明锥桶贴边，车却明显往锥桶那边蹭

#### 方案（冻结待用）

```
检测  在前向扇区找"在通道内且明显近"的回波:
        |x| < 车道半宽 - 50mm         (排除边界管子自己)
        200mm < 距离 < 1500mm         (太近=已撞, 太远=不用管)
        y > 0                         (只关心车前方)
      取最近的一个作为障碍物, 记 (x_obs, 距离)

执行  把"横向目标"临时推到障碍物对侧(只偏横向, 不改目标速度 -> 不引入停车):
        cx_eff = cx + sign(x_obs) x dodge
        dodge  = min(可用余量, 障碍半宽 + 安全边距) x 接近度
        可用余量 = 车道半宽(实测 paodao/2) - 车体半宽(130mm)   <- 自动定标, 不写死
        接近度   = 距离 1500mm -> 300mm 之间由 0 线性升到 1

方向自检  cx 变大 => 车更靠左 (因为 err=cx-x_中线, 平衡时 x_中线=cx)
         所以障碍在左(x_obs<0) => cx_eff 变小 => 车向右让开 OK
```

**为什么用 `cx_eff` 而不是新加一个转向项**：复用现有"通道中线跟随"控制律，不引入新的增益与振荡源；而且 `cx` 已经有标定与验证路径。

**注意**：车道半宽用**实测** `paodao_distance/2`，所以"有锥桶处管子外扩"会被自动跟上——这正是"有锥桶就增大宽度"的设计所对应的行为。

## 6. 上车安全清单（**没有停车逻辑**）

1. **上电即跑**：`Speed_mubiao` 固定、TIM5 一初始化速度环就启动，没有任何等待/许可
2. **永不自动停**：近墙、感知无效、数据过期、DMA 故障、雷达断流都**不会**撤销驱动；停车只能切断电机供电
3. **先架起驱动轮再上电**（或用手按住）
4. **手放在电源开关上**再放上赛道
5. `get` 是阻塞回复（21 行 ≈ 250ms 主循环停摆）——**停车或架空时再发**
6. 采集前先 `tele 0`，否则二进制流会把 INFO 回显冲掉导致握手失败（C14）

### 11.4 复核给的方向（接受）

> 优先把转向改成**连续路径跟踪**：弯道入口触发状态，弯中持续依据边界/路径更新曲率；
> **缺少入口断点 ≠ 出弯**。出弯要结合近远段方向、边界连续性、偏差，不能只看某点误差或一条线的 k。

**因此下一步优先级调整为**：

| 优先级 | 做什么 | 解决 |
|---|---|---|
| **P1** | **单侧边界推算中线**（一侧可见也能给出通道中线） | 350/352 个无效帧（C15/C16） |

| **P3** | **方向一致性仲裁**（迟滞：反向需明显更近或持续若干帧） | C4 / 第 9 项 |
| **P4** | 350ms 到期路径：到期只用于"重新评估来源"，不直接批准弱中线回正 | 第 8 项 |
| 保留 | `dy` / `sk` / `slew` / 220ms / 12-4 门槛 | 已生效的缓解项，不再当主修 |
