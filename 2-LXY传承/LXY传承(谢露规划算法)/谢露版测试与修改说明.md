### 算法流程(每帧雷达数据)

```
雷达帧(0x54, 47B, 12点/包, LXY 解析器)
  → 360°排序 → 后轮筛选(角度 0-250 与 290-360)
  → 尖峰滤波(距离≥100, y>-200)
  → 断点检测(连续 4 点 ≥350mm 跳变 → 左/右墙数组)
  → 6× 极坐标滤波(只留 y < dd 的墙点) → 2× 平面跳变截断
  → 三分支:
      ① 双侧断点 < zd     → 本帧不动舵机
      ② 双侧断点 > zd     → 两墙角度加权平均(K_ave) → 模式 R_CL/L_CL
                            → paodao_G1 + nihe_G1 → qianfang30_PD
      ③ 单侧断点          → ZW_ave + Midline_fit_2 → 模式 YZ_j/ZZ_j
                            → 只测未断侧宽度 → ZW_G1 → qianfang30_PD
```

**qianfang30_PD**:`err = (a×归一化角度 + d×归一化偏差 [+ZW×S弯特征]) × 275`,限幅 ±275;
`servo_pwm = 1445 + kp×err + kd×(err−err_1) + ki×err_sum`,输出钳位 1170~1720。
拟合角度 <65° 直接打满右(1170),>115° 打满左(1720),绕过 PD。
**模式切换不清零误差状态**(函数内 static,谢露原语义)。

## 二、操作区别(重点:蓝牙命令变了)

### 新蓝牙命令表(9 条 + get)

| 命令 | 绑定参数(同写) | 缩放 | 默认回显 |
|---|---|---|---|
| `kp` | 曲线 kp:R_CL_kp + L_CL_kp | ÷1000 | 500 (=0.5) |
| `kp2` | 直角 kp:YZ_j_kp + ZZ_j_kp | ÷1000 | 900 (=0.9) |
| `kd` | 曲线 kd:R_CL_kd + L_CL_kd | ÷1000 | 300 (=0.3) |
| `kd2` | 直角 kd:YZ_j_kd + ZZ_j_kd | ÷1000 | 130 (=0.13) |
| `sp_kp` | Speed_pid.kp | ÷100 | 850 (=8.5) |
| `sp_ki` | Speed_pid.ki | ÷1000 | 505 (=0.505) |
| `spd` | Speed_mubiao | 1:1 | 8 |
| `zd` | zhuandian(断点阈值) | 1:1 | 200 |
| `dd` | Duandian_d(墙点 y 带通上限) | 1:1 | 700 |
| `get` | 回显全部 | — | — |

**已删除的旧命令**:`kp3`、`kd3`、`disr`、`disl`、`yr`、`yl`、`ystra`、`ysel`、`angle`(发送会回 `ERR name`)。

**语义变化**:旧 `kp`=直道 PD,新 `kp`=**曲线** PD;旧 `kp2`=大转弯 PD,新 `kp2`=**直角** PD。旧手册里的"kp 45→0.045"对应关系作废,现在是"kp 500→0.5"。

### 模式号(pid_slt)语义

| 值 | 含义 |
|---|---|
| 0 | 未决策(首帧/被守卫跳过,舵机保持) |
| 1 | 右曲线 R_CL |
| 2 | 左曲线 L_CL |
| 3 | 右直角 YZ_j |
| 4 | 左直角 ZZ_j |

遥测第 5 通道(pid 模式)与 USART3 的 `pid_slt=...` 打印均用此语义。

### 全部参数默认值(谢露原值)

| 参数 | 默认 | 说明 |
|---|---|---|
| R_CL_a / L_CL_a | 0.6 | 曲线角度权重 |
| R_CL_d / L_CL_d | 0.1 | 曲线偏差权重 |
| R_CL_kp / L_CL_kp | 0.5 | 曲线 kp(蓝牙 `kp`) |
| R_CL_kd / L_CL_kd | 0.3 | 曲线 kd(蓝牙 `kd`) |
| R_CL_ki / L_CL_ki | 0 | 曲线 ki(未用) |
| YZ_j_a / ZZ_j_a | 0.6 | 直角角度权重 |
| YZ_j_d / ZZ_j_d | 0.6 | 直角偏差权重 |
| YZ_j_ZW / ZZ_j_ZW | 0.12 | 直角 S 弯特征权重 |
| YZ_j_kp / ZZ_j_kp | 0.9 | 直角 kp(蓝牙 `kp2`) |
| YZ_j_kd / ZZ_j_kd | 0.13 | 直角 kd(蓝牙 `kd2`) |
| YZ_j_ki / ZZ_j_ki | 0 | 直角 ki(未用) |
| zhuandian | 200 | 断点阈值(蓝牙 `zd`) |
| Duandian_d | 700 | 墙点 y 带通上限(蓝牙 `dd`) |

> a/d/ZW 没有蓝牙命令,要改需改 `HARDWARE/XIELU/xielu.c` 顶部参数初值。

## 四、常见问题与调节

| 现象 | 处理 |
|---|---|
| 直道画蛇 | 蓝牙 `kp` ↓(曲线);若仍抖改 xielu.c 的 R_CL_a ↓ |
| 弯道内振荡 | 蓝牙 `kd` ↓(曲线)/ `kd2` ↓(直角) |
| 入弯不触发/过早触发直角 | 蓝牙 `zd` ↑/↓(断点阈值) |
| 弯道响应偏慢或偏早 | 优先怀疑**角度基准差 5°**:谢露装法 +85° 旋转 vs 本车 +90°。先用 `zd`/`dd` 调,不行再改 `xielu.h` 常量(CL_jixianjiao 65 / LR_bianjiejiao 60 / zhuan_a1_L 120 / zhuan_a1_R 60)±5° 重标定 |
| 换赛道 | 重标定 `xielu.h` 常量(Start_dis / End_dis / chekuan / zhuan_a1_L/R 等) |
| 发旧命令(kp3/disr/…) | 回 `ERR name`,属正常——命令已删除 |
| 速度环问题 | `sp_kp`/`sp_ki`/`spd` 用法与旧版完全相同 |
