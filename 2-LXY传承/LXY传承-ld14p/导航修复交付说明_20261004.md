# LD14P 导航修复交付说明（2026-10-04）

本次只修改 LD14P 工程。依据同日三次遥测，落实感知参考、近障碍、转向仲裁、速度降级和诊断采集调整；新增逻辑均有中文注释。固件未烧录、未做实车闭环验证。

## 已修改行为

| 部分 | 改动与目的 |
|---|---|
| 扫描输入 | 每个角度独立保存最近观测、坐标与估算时间，200ms过期；缺块/异常转速清缓存，未知空间不当作空旷。继续保留CRC和跨DMA包拼接。 |
| 运算路径 | 中线计算由重复全表搜索改为角度索引；主循环左右边界单次遍历提取。缓存坐标供近障碍与绕行复用。实际板端耗时待测。 |
| 小弯参考 | 去掉边界75%～95%索引窗口，拟合外侧墙x=a*y+b；至少6点、y跨度250mm、均方根残差不超过60mm、最大外推250mm。10月4日约17cm参考不能再作为1.2m前视。 |
| 直道纠偏 | 移除mode0固定±200误差裁剪，保留全局±500、输出限幅、跨模式清微分；固定前视也限制过远外推。 |
| 近障碍 | 独立检测前方车身走廊内的相邻回波簇，远背景不再清空锥桶；100～200mm的有效近回波进入停车判断。转向较大时额外扩大检测走廊。 |
| 绕行 | 狭窄障碍仅在车宽余量走廊有充分可通行回波证据时，以低速输出绕行舵角；路径未知、近距离或两侧不足时撤驱动。宽墙与小目标分开处理，远宽墙+有效弯道允许低速接近。 |
| 反向仲裁 | 普通反向需两个不同时间的侧墙观测并间隔至少60ms；重复缓存不算第二次。超过200ms还无法确认则撤驱动。独立避障可覆盖循迹并清旧转向锚点。 |
| 速度环 | 用户请求Speed_mubiao与实际Speed_effective分开；TIM5仍是唯一电机输出者。降速/撤驱动重置积分，补上PI积分与限幅前输出遥测，保留500ms锁停且不可用drive 1解除。 |
| 蓝牙 | CONTROL提升优先级，HEALTH入队失败会重试；发送完成后由ISR衔接下一整包，不再等主循环处理完雷达才启动下一包。停止命令即使回执队列满也优先执行。 |
| 上位机 | 兼容旧DETAIL schema1及新schema2；报告显示全文件控制/DETAIL数量，明确协商是否完成。新固件采集时先drive 0、配置完整且日志就绪后drive 1，正常结束/按钮停止后drive 0并续收2秒。异常退出尽力发送停止，不把发送成功当作实车已停。 |

## 实车尺寸与初始参数

用户测量：含车轮总宽约250mm，雷达旋转中心到车体最前端约180～200mm，代码按200mm配置。

参数集中在 `HARDWARE/LEIDA_DATA/LEIDA_DATA.h`：

- 半车宽125mm，每侧余量50mm；雷达至车头200mm。
- 障碍检查距离1000mm；近障碍停止阈值400mm，从雷达中心量起，约等于车头前200mm。**这不是经过实测的制动距离。**
- 缓存点最大年龄200ms；角度与转速推算点年龄并额外扣3ms包尾余量，未使用真实逐点发射时间，也未做车体运动补偿。
- 自动绕行 `NAV_ALLOW_AVOID=1`。候选通道需通过带车宽的路径检查，仍需标定舵机转角与实际轨迹。

导航限速由 `LEIDA_NavigationCommand()`集中返回：正常上限8、弯道6、绕行/换向确认/远宽墙4；未知前方、无效参考、近障碍或无绕行空间为0。单位仍是原编码器速度单位，不是m/s；用户设置比这些上限更低时取更低值。

没有新有效控制时，TIM5在100ms限至4、200ms撤驱动，500ms锁停。零PWM只撤去推进力，不是主动制动。

## 新诊断字段

DETAIL schema2总长232字节，前160字节payload沿用schema1，追加10个uint32和4个float。CONTROL/MOTOR中目标速度现在是实际送入速度环的Speed_effective；CONFIG的spd和DETAIL的requested_speed保留用户请求值。

| 字段 | 含义 |
|---|---|
| reject_reason | 0无拒绝，1窗口，2中线几何，3外墙参考，4其他退化/非有限数 |
| candidate_mode / candidate_pwm | 进入转向保持与独立避障前的候选模式/舵机指令 |
| navigation_action | 0前方覆盖足够且无走廊障碍，1未知，2障碍，3左绕行，4右绕行 |
| front_bins / left_bins / right_bins | 仍在有效期内的角度桶数量 |
| max_point_age_ms | 当前有效缓存的最大估算年龄 |
| speed_limit_reason | 0正常，1感知不足，2障碍，3换向确认，4弯道，5控制更新超时 |
| pending_direction | 0无待确认，1右，2左 |
| requested_speed / effective_speed | 用户请求速度 / TIM5实际应用速度 |
| obstacle_x / obstacle_y | 当前最近走廊障碍坐标；须结合navigation_action解释 |

小弯DETAIL的ref_x/ref_y为拟合墙线上目标前视位置；ref_dy为超出真实y覆盖区间的外推距离，不再是旧算法的“最近原始点距目标距离”。固件CONFIG units中已更新语义标识。旧上位机不能解新DETAIL，因此与本次LD14P上位机文件配套使用。
