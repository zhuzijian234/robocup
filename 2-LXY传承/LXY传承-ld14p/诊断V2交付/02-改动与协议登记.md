## 状态真实性

CONTROL仍按原设计偏移，mask bit0～25为核心字段，26原始槽数、27转速、28输入时刻、29控制完成时刻、30控制间隔。bit31保留。首个控制间隔无效，不用全1时间哨兵。

非PD动作模式值置0、err/mode不标记本次更新；本实现保守地清除它们的valid，避免旧误差混入分析。动作1=PD、2=保持、3/4=强制左/右、5=感知无效。motor_state反映启动抑制/允许驱动/故障锁定，不等于实测电机是否转动。舵机值为最终CCR指令，不是角度反馈。

拟合未执行或退化时不把旧斜率声明为新有效拟合。主循环对斜率作符号归一后，提交读取最终值。无效输入只保留能够确认的点数、执行器/速度及时间量，不保留旧几何字段的有效标志。

当前raw>0表示按LD14P包头读取到距离槽，因此raw/转速标有效；raw=0时没有可靠解析，扩展有效位清除。转速单位dps，不能直接填RPM或Hz。原始CRC尚未校验，这里的valid不等于雷达包通过CRC。

## CONFIG键注册表

TLV：key u16、type u8、length u16、value；1=u32、2=i32、3=float32、4=UTF-8、5=bytes。配置目前30片，每片一个TLV，接收端也支持TLV跨片。快照期间拒绝参数写入，避免混合revision。

| 键 | 内容 |
|---:|---|
| 1 | 布局rc26-mask31-v2.1 |
| 2 | 源码内容摘要标识；完整摘要见source_manifest |
| 3、4、5 | lidar_id、algorithm_id、input_kind（0块/1扫描） |
| 6、7 | 蓝牙UART波特率、抽样rate |
| 8、9 | 失效保护500ms、正常HEALTH1000ms |
| 10 | 单位和保持次数/PD差分语义 |
| 11、12 | DMA字节容量、算法点容量 |
| 13 | 本算法主要几何/输出约定；完整常量以构建源码为准 |
| 14 | 当前LD14P标称点率、PWM及未校验CRC的声明 |
| 100～115 | 依次kp、kp2、kp3、kd、kd2、kd3、sp_kp、sp_ki、spd、disr、disl、yr、yl、ystra、ysel、angle，float32原始位 |

CONFIG登记了主机布局，主机软件版本保存在meta。不会把缩放整数get结果当作float32备份。配置文本中的固定常量必须随算法/雷达移植同步修改，不能只改型号编号。

## 发送和计数

- ACK/事件优先，CONFIG/HEALTH其次，CONTROL/VOFA最后；同优先级保持入队顺序。只有选中待发帧才分配V2 tx_seq，优先级重排不会倒退。
- 入队失败丢完整消息并计数；配置等待普通槽空闲，不把每次重试都记为一次丢包。
- 参数写入先确认ACK/事件空间，当前主循环边界应用；速度中断读到新值前revision也在短临界区更新。没有整组原子调参。
- EVENT1参数应用、2拒绝、3失效保护状态变化、4发送丢弃计数变化。事件不能替代完整配置，丢事件后revision未知区间需getcfg补齐。
- HEALTH中UART雷达错误、DMA硬件错误、整圈溢出和软件RX队列峰值目前未实现，unsupported_mask的5、6、8、12位置1。本轮不把零占位冒充已测零错误。BLE命令接收溢出、输入块覆盖、TX丢弃、处理耗时已接入。
- HEALTH正常1Hz，保护锁定时5Hz；主循环卡死时不能发心跳，主机超时仅报告设备/链路无响应。HEALTH不是ISR发送，也不改变500ms保护逻辑。

## 时钟与限制

TIM6按84MHz定时器时钟分频至1MHz，1000计数产生1ms中断。主机采用设备控制时刻建立时间轴，主机接收时刻另存。uint32毫秒回绕可展开；间隔太大或回退分段。长时间屏蔽中断可能漏计时器溢出，不宣称任意长临界区下时钟准确；需实测ISR/临界区上限。

本轮关闭主控制路径大量USART3 printf以减少串行阻塞，这是可观察的节奏变化，需重新建立跑圈基线。未改变原PD差分公式、控制参数、雷达PWM97、DMA1798字节或500ms失效保护。

V2报告使用动作和有效位，缺口/会话/参数变化不做连续PWM差分；默认给出周期、动作、速度误差和健康/配置证据，不复用旧V1的固定帧窗自动调参告警。GUI V2任务目前无实时曲线。旧V1不具备有效位/设备时钟，保留兼容不等于补齐其诊断能力。

资源说明：6个发送槽的数据区合计1536B，描述符另约48B，因此TX子项略高于早期1536B建议；新增诊断静态状态合计仍在2816B总预算内，栈增量单列。输入完成时间是处理DMA完成中断时读取的时钟，包含中断响应延迟，不冒充硬件捕获的激光采样时刻。
