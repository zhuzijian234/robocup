# M10P四次S弯视频遥测复核与小幅优化建议

日期：2026-10-12。仅分析，未修改固件、上位机业务代码或HEX。

## 1. 结论

当前S弯已经具备连续通过和及时换向的能力，220116、220417应作为新的良好实车基线。优先改善“换向后近远段接管不连续”，不宜全局增加Kp、扩大预瞄或取消换向确认。

另一个需要验证的点是：当前急弯入口外移确实会在连续S弯的单个弯段中触发。瞬时`s_preview=0`不能证明整段道路已经不属于S弯。应先做有无该偏移的回放比较，不能直接认定删除一定更好。

## 2. 实际阅读和核对范围

- 阅读`调试视频/S弯拆解_遥测对照_20261011/README.md`及拆解脚本、四组概览图、良好样本换向阶段30fps密表。
- 解码四个原始MP4，分别219/226/214/211帧、30fps；抽查6个帧位与拆解JPEG，平均绝对像素误差均小于1，符合JPEG重编码差异。
- 使用当前上位机正式解析器重新读取四组原始BIN；按`session/control_seq/param_revision`关联CONTROL、DETAIL、PATH_EXTRA、RACE，不从视频叠字统计控制次数。
- 四份BIN的SHA256均与meta一致，V2 CRC/结构错误候选为0，已接收报文tx序号缺口为0；这不等于板端诊断发送没有丢弃。
- 四组均为`sha256-d97f9c6d1f380d38`，17/15、cx10、preview700；是上轮急弯修改后的数据。
- 每组8份点云均完整导出，共32份；未覆盖所有关键换向帧。

### 时间与统计限制

原拆解将视频开头假设为遥测连续运动起点。视频无同步标记，而且开头有人扶车，轮速非零不证明车身已平移；“所有视频帧映射到非零轮速”只能证明窗口落在轮子转动区间，不能证明精确同步。

原报告A、B两种对齐相差0.66～2.77秒，属于两种假设的差异，**不能当作经过验证的误差上界**。以下视频阶段与控制序号分别解释，不将某张视频帧与某条遥测严格绑定，也不据此断言应提前多少毫秒。

原README按30fps视频帧重复引用约12Hz控制记录，其中“良好样本没有触及PWM限幅”与原始CONTROL不符：220116正式窗口有3帧、220417有2帧触及1170/1720。瞬时触限并不推翻表现良好，但说明不宜盲目继续增大力度。原README有部分图表/计数不一致，以下采用本次原始BIN复核。

## 3. 四组正式采集窗口概况

| 组别 | 正式CONTROL数 | 正常应用/保持/无几何 | 缺少DETAIL / PATH_EXTRA | 完整点云 |
|---|---:|---|---:|---:|
| 215921 | 80 | 62 / 5 / 13 | 3 / 3 | 8 |
| 220025 | 64 | 60 / 2 / 2 | 1 / 1 | 8 |
| 220116，表现良好 | 62 | 57 / 2 / 3 | 0 / 0 | 8 |
| 220417，表现良好 | 60 | 53 / 4 / 3 | 3 / 3 | 8 |

“无几何”按action_reason=5统计；保持按action_reason=2。gate_reason与action_reason不是同一枚举，不能混读。表中窗口由meta的正式起止时间和会话筛选，不能拿不同长度窗口直接排名。

相邻连续控制序号的间隔76～92ms，中位约79～81ms。220025缺3883，220116缺4497、4498；后者记录间距246ms，但4499自身报告的控制周期为78.463ms，input_drop为0且存在tx_drop。这更符合诊断记录缺失，**不能把246ms直接报告为控制阻塞**。

正式窗口处理耗时最高分别8.310/8.018/7.588/7.501ms，没有证据表明良好样本因几何计算持续超时而换向迟缓。

## 4. 已经做得好的部分

视频中两组良好样本均能完成连续左右方向改变，运动过程明显比早期无法持续换向的表现完整。部分画面靠边，但手持透视和遮挡不支持精确侧隙或“全程无接触”的结论。

220116的三个明确换向序号为4507、4523、4538；220417为6680、6698、6713，均能切换到新弯向并建立输出。比如220417：

- 6696：PWM1444，接近中位；近方向约0，远方向已向左。
- 6697：道路误差−6.96mm，处于小误差区，保持1444。
- 6698：误差+39.85mm，近远方向均向左，当帧确认换向，PWM1460。

这段只有一帧小误差等待，不能认定为严重锁舵。S预告已有提前收旧弯舵量的作用，当前优先保留。

## 5. 最值得完善的地方

### 5.1 近远段突然切换，造成换向后的短暂收舵——最高优先级

| 组别/序号 | 实测表现 | 直接原因 |
|---|---|---|
| 220417，6699→6700→6701 | PWM1499→1456→1558；目标x约−90→−9→−267mm | 有效单侧远段切到双侧近段，ref_y约707→442→700mm；随后恢复远段 |
| 220116，4538→4539→4540 | PWM1397→1431→1303；方向均在建立右弯 | ref_y700→401→700mm，近区双侧目标暂时削弱新弯输出 |
| 220116，4508→4509→4510 | PWM1170→1266→1178 | 远段斜率1.905超过1.8门槛，被拒后改用近段；下一帧远段恢复 |
| 220417，6715→6716→6717 | PWM1277→1346→1181 | 6716远段斜率1.813刚超过1.8，退回近段 |

生产代码中“双侧近段+单侧远段”接管需要接缝差≤80mm、斜率差≤0.8等条件：

- 6681左近/远段斜率差0.826、接缝位置差89.79mm，两个条件均未通过；左远段本身仍有8个分区和662mm跨度，却不能作为最终远目标，输出退回415mm近区目标。
- 6700右近/远段斜率差0.970、接缝差78.49mm；主要被斜率差门槛挡住。
- 下一帧另一侧近段点数变少，来源改为单侧，又不再走同一双侧接管门槛。由此可出现“近侧观测增加，远目标反而丢失”的输出不连续。

**建议**：统一双侧与单侧接管的几何依据。近段负责局部居中，单侧远段提供趋势，必须验证同墙轮廓、实际连接区域与通路，不能简单将斜率差门槛从0.8全局调大。对高斜率直线候选优先比较有支持的局部折线/切向，避免用增大斜率上限硬接横墙。

若需一帧过渡，仅在本帧仍支持同方向、旧远段刚失效、没有反向/避让证据时启用；正常出弯仍允许及时减舵，不延长全局锁舵。

### 5.2 区分连续S弯阶段与瞬时S预告——第二优先级

正式RACE中：220116的4508记录outer_offset=−10mm，4524为+10mm，4528为+25mm；220417的6680为−10mm、6704为+15mm、6720为−25mm。表明急弯外移在这一组连续S弯中有实际参与。

原因是`s_preview`只表达当前近远方向相反；车进入下一弯后近远会重新同向，瞬时S标志自然消失，急弯入口分支即可重新满足条件。此前“遇到S预告就退出外移”的实现不能等同于“整段S弯都禁止外移”。

**建议**：以可靠近远反向和已完成换向记录一个短期S过渡阶段，用于限制额外外移，不阻止舵机换向。退出依赖持续单弯/直道证据并有超时上限，避免把S弯之后真正的大急弯一直当成S弯。先比较当前偏移与减弱偏移的回放，不能凭照片断言这25mm有害，也不建议直接全局关掉。

### 5.3 换向时机微调——第三优先级，先观察前两项效果

目前主要问题更像“已判断换向，却被目标切换打断”，不是始终看不到下一弯。不要先全局减小30mm反向门槛，也不要删除两帧确认。

后续若仍有残余迟疑，可在近段和远段均支持新方向、当前可见通路支持且远离障碍的情况下，让小误差区更顺畅地释放旧弯舵量。弱证据仍保留确认；先做候选输出旁路记录，核对是否误伤直道居中或急弯持续转向。

`turn_distance_mm`目前在S预告时直接取近段参考距离，不是实际测出的拐点距离。不能直接用“距离/车速”设计精确换向倒计时；还缺物理速度与舵机响应标定。

### 5.4 末段近场边界消失——独立记录，不贸然放宽全局门槛

220116的4553～4555、220417的6728～6730均连续3帧无有效近段；保持上一PWM，随后恢复。点云显示近墙有效段从约4个分区缩到3、2个，前方还另有较远墙段，中间存在明显断开。

两组均发生在视频/采集后段附近，但因缺少精确同步且视频最后有人接车，不能断言一定对应第二弯，也不能把远处墙段直接跨空隙拼成当前道路。

保留为后续短段恢复的反例：先补同步/固定机位和该处点云，再考虑同墙身份、切向、空间余量共同约束的短段模式。不全局把4个分区降到2个，不把无几何自动解释为雷达串口断流。

## 6. 锥桶判断和其他性能

220025正式末尾3944/3945出现候选/ACTIVE，3945避让量约−70mm；视频末尾有人入镜，概览局部也能见到赛道外的红色物体，缺少同步和该触发点云，不能断言为误识别或实际赛道锥桶。暂不据此修改避让门槛。

建议下一轮保持17/15、cx10、Kp/Kd、基本预瞄700及速度规划不变；先只做近远段接管的针对性改进，再验证S阶段外移是否需要削减。无需重写整个控制架构，也不恢复自动停车。

验收应保留这两组良好样本作为基线，同时验证直道、长缓弯、左右大急弯和单侧锥桶。重点比较：有效路径连续性、换向后反复收舵次数、舵量触限持续时间和最小实际侧隙。不能只以“更早打方向”判定更好。
