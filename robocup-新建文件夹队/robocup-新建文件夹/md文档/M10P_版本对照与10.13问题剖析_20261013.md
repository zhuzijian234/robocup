## 2. 当前版本（C）相对 A 版改了什么

**共 3 个文件、24 行新增 / 11 行删除。** 用 `git diff 3c1af22 3bfa2f0 -- <project>/HARDWARE <project>/USER <project>/test` 可完整复现。

### 2.1 改动 1（`path_track.c:1111`）：急弯分支的预滤波

```c
// A 版（3c1af22）
if (out->model || (!state->acute_phase &&
    !((out->far_fit[0].valid && fabsf(out->far_fit[0].a) > .30f) ||
      (out->far_fit[1].valid && fabsf(out->far_fit[1].a) > .30f))))
{ acute_clear(state); return; }        // ← 要求"某侧远段拟合有效且 |a|>0.30"

// C 版（当前）
if (out->model || (!state->acute_phase && out->straight))
{ acute_clear(state); return; }        // ← 只跳过"已确认的直道"
```

**理由 [事实]**：
- 预滤波在 `acute_wall()` **之前**（`acute_prepare()` 门限链第 5 步），它只需负责"直道上省掉分区扫描"。
- 实测 10/12 T01~T07（`fw=9b8c0a52` = A 版）的 181 行 race 里，`acute_phase>0` 只有 **1 行**；10/13 六组的 249 个 acute 事件里 `确认`2 次、`准备`1 次、**`主弯`0 次**。
- 进弯前那一刻 `|近a|` 中位数只有 **0.09~0.11**（近段本来就该是直的），而远段窗口在弯口常因"点数/跨度不足"被拒 → **"要求远段"把证据链断在第一步**。

**为什么不会误激活其他弯道 [事实 + 结构性保证]**：
- S 弯 `s_preview`、锥桶 `avoid_state` 在**更前面**（门限链第 1 步）已 `ACUTE_PRIORITY` 返回；
- 缓弯达不到 `acute_wall()` 的门限（种子≥8 点、≥5 个 50mm 分区、跨度≥200mm、RMS≤12mm、连续 3 分区向内偏≥40mm、400mm 内切线转过≥0.60rad）——**这些门限一字未改**；
- 未确认急弯时输出走 `baseline_curve_offset()`（原有 25mm 微调）→ 与 A 版逐帧相同。

### 2.2 改动 2（`path_track.c:22`）：外侧目标上限

```c
#define ACUTE_OUTER_MM 70.0f   // A 版为 40.0f
```
`goal = fminf(ACUTE_OUTER_MM, available)`，而
`available = width*0.5f - 130*cosf(yaw) - 345*fabsf(sinf(yaw)) - 40`（`path_track.c:1150` 附近）
→ **40mm 的贴墙余量由算式保证，不靠这个常量**。宽 500 / yaw≈0 时 `available=80`，取 70 留 10mm 余量，此时车心离墙 `250-70-130 = 50mm`（A 版 40 时为 80mm）。窄道按 `available` 自动降。

### 2.3 改动 3（`test/test_acute_stages.c`）：测试里的硬编码常量

把 5 处硬编码 `40` 换成 `ACUTE_OUTER_MM`（该测试 `#include "../HARDWARE/CENTRE_LINE/path_track.c"`，常量可见）。**行为性断言一字未动**（`goal>0`、`outer_offset*side<0`、`|target_x-10|<15` 全部保留）。

### 2.4 改动 4（附带）：`diag_build_id.h`
