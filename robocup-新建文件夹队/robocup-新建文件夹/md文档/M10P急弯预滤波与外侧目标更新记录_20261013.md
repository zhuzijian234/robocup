## 2. 为什么改

### 改动 1（预滤波）
- 预滤波位于 `acute_prepare()` 门限链**第 5 步**，在 `acute_wall()` **之前**；它的职责只是"直道上省掉分区扫描"。
- 实测：10/12 T01~T07（`fw=9b8c0a52` = A 版）181 行 RACE 里 `acute_phase>0` **只有 1 行**；
  10/13 六组（`fw=59f2128e`）249 个 acute 事件里 `确认`2 次、`准备`1 次、**`主弯`0 次**。
- 进弯前那一刻 `|近a|` 中位数只有 **0.09~0.11**（近段本来就该是直的），而远段窗口在弯口
  常因"点数/跨度不足"被 `FIT_POINTS|FIT_SPAN` 拒掉 → **"要求远段"把证据链断在第一步**。

### 改动 2（外侧目标上限）
- `goal = fminf(ACUTE_OUTER_MM, available)`；`available = width/2 - 130*cos(yaw) - 345*|sin(yaw)| - 40`
  → **40mm 贴墙余量由算式保证**，与该常量无关。
- 宽 500 / yaw≈0 时 `available=80`；取 70 留 10mm 余量，车心离墙 `250-70-130 = 50mm`（A 版 40 时为 80mm）。窄道按 `available` 自动降。

## 3. 为什么不会影响其他弯道类型

结构性保证，位于预滤波**之前**：
- **S 弯** → `s_preview` → `ACUTE_PRIORITY` 直接返回；
- **锥桶** → `avoid_state != AVOID_CLEAR` → `ACUTE_PRIORITY` 直接返回；
- **缓弯/直道** → 达不到 `acute_wall()` 的门限（种子≥8 点、≥5 个 50mm 分区、跨度≥200mm、RMS≤12mm、
  连续 3 分区向内偏≥40mm、400mm 内切线转过≥0.60rad）——**这些门限一字未改**；
- 未确认独立急弯时输出走 `baseline_curve_offset()` → 与 A 版**逐帧相同**。

## 6. 未验证 / 风险

1. **本改动只保证"分支会启动、状态机正确、其他弯道逐帧不变"，不保证实车能过急弯。**
2. `acute_wall()` 能否在真实点云上给出 `valid==2` **没有回放过**（现有夹具是合成/派生序列）；
   手上有 13 组 × 8 = 104 份真实 `cloud.csv` 可做这件事。
3. 70mm 是**候选值**，不是标定值。
4. 即使偏移量在指令上给满，**车的实际横移仍是开环的**（固件不测量"车到没到外侧"）。
5. 偏移量实际下发 = `ACUTE_OUTER_MM × weight`，而
   `weight = clamp((acute_distance - 700)/250, 0, 1)` → **越接近弯偏移越小，700mm 处为 0**。
   这是设计行为，不是 bug；但会导致"实际偏移看起来达不到设定值"。
