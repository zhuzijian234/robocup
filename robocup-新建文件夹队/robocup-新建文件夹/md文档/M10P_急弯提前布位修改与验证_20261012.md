## 1. 本轮行为

直道/弯道速度仍为 **17/15**，`cx=10`；原 Kp/Kd、PWM 极限、PA5 电机输出、编码器 PI、普通循迹、S 弯换向和锥桶避让仍保留。不增加自动停车。

新增分支处理“有明确入口证据的独立急弯”。右弯先向左准备，左弯先向右准备；目标是相对近处道路中线向外最多 **40 mm**，不是在每一帧累加 40 mm，也不是把已在弯内的远目标简单外移。40 mm 是首轮试验上限，车身位置与航向变化不保证实际能够完全达到它。

控制流程：

1. **OFF（0）原循迹**：缺少入口证据时保留回退版输出。
2. **CONFIRM（1）入口确认**：近处两条独立连续墙均可靠；外墙在有限距离内持续向弯内偏折。连续两帧同方向才进入准备。
3. **PREPARE（2）外侧准备**：用近墙估计前轴处的法向位置及局部道路航向。位置目标至多40 mm，并受通道宽度、当前姿态投影及可见占用约束。沿近切线生成局部目标，进入主弯前逐渐接回原路径。
4. **TURN（3）主转弯**：可见弯墙特征进入700 mm范围、近处已经明显转弯或连续弧形模型接管时，停止继续追外移。进入此阶段后不退回准备。只有经过本轮准备的弯能启用新增的短时减舵限制。
5. **EXIT（4）出口观察**：看到原算法认定的直道后观察两帧并清除新状态；减舵仍交给原控制器，不另加固定延时锁舵。出现S弯/反向/锥桶证据立即交回原分支。

断流、过期扫描、接收代次变化、参数修改和无有效几何均取消新增布位状态。不会把无效点云强行标成有效。

## 2. 识别和控制细节

`HARDWARE/CENTRE_LINE/path_track.c` 中的 `acute_wall()`：

- 从相邻射线的连续回波簇确定墙面身份，允许外墙跨越 `x=0`。
- 每面墙复用固定24个50 mm分区；100～400 mm段至少5个分区、跨度至少200 mm，近线法向残差不超过12 mm。
- 外墙连续3个分区偏离近切线至少40 mm，后续连续200 mm段切线变化至少0.60 rad。可见尾部反向或转角显著回落，拒绝当成独立急弯。
- 左右近切线角差不超过0.12 rad；准备时局部航向不超过0.22 rad，局部宽度390～650 mm。
- 新分支不会放宽原近远拟合合法性，也没有恢复先前实车退步的近远拼接或六帧S弯抑制。

准备目标使用450 mm局部参考；`ACUTE_FULL_PREP_MM=950`以上采用局部准备目标，在950～700 mm间逐步接回原路径，进入700 mm范围交还主弯。**这里的距离是可见弯墙偏离近切线的位置，不是真实拐点、前轴到弯口距离或预测碰撞距离。** 阈值是本轮待实车验证的保守参数，不能用先前错误的“近远直线交点约650 mm”作标定依据。

位置参考在前轴，雷达到前轴100 mm。入口余量采用260 mm轮外宽；前轴至后轮外廓305+40=345 mm，用这一偏心参考计算保守姿态投影并留40 mm几何余量。仅检查当前局部走廊及可见占用，未声称完成未知侧后方、转向轮或未来运动的完整扫掠校验。

控制器区分原道路目标与准备目标，防止向外准备被当成S弯反向。准备时不叠加参考切换产生的D项，单次准备指令变化限制为45个PWM计数；**这个限制不施加在主弯接管、普通循迹或S弯反向上**。

r2进一步检查阶段交界：若整条近远路径已经反向，即使没有`s_preview`标志，也当帧撤销旧入口；近处通道宽度越界不会被当成“主弯到了”。只有同向证据才能从准备转入主弯。连续PREPARE→TURN时，若当前近段及目标方向均支持已确认急弯，允许当帧覆盖上一弯残留的`bend`，即使本帧远段暂时失效；权限仅限接管帧，退出准备后的普通反向仍沿用原确认规则。

确认后的主急弯若远段失效、当前近段仍与上一帧同向且航向连续，将原漏掉的斜率0.35～0.6区间纳入保护。该事件最多两帧，每帧允许归一化误差减小40 mm，同一连续主弯不反复续期。真实出弯、反向、锥桶或长间隔立即退出。未进入新阶段时仍使用原80 mm规则。

## 3. 为什么保留25 mm微调

连续回放发现，旧25 mm远目标微调也参与已有S弯中的部分正常输出；直接整体删除会改变这些序列，而只用“近远同向、远角度大”启动新的主弯保护，也会使S弯减舵变慢。

因此将旧逻辑明确命名为 `baseline_curve_offset()`：新阶段未接管时使用它；准备/主弯阶段停止它。两者不叠加。保留的是仍被调用且有回归依据的功能；删除了新增过程中只写不读的冗余位置状态。

新逻辑不在已经进入弯中、但缺少此前入口证据时强行启动。因此本次保存的近弯口快照输出保持基线，并不代表新增提前布位已被这些快照验证成功。

## 4. 遥测及上位机

主CONTROL、DETAIL、PATH_EXTRA、MOTOR、CLOUD包长不变。低频RACE升级到 **schema 3，176字节**，仍每4个控制序号最多一帧。相比148字节的schema 2，每帧增加28字节；12 Hz控制频率下约增加84字节/秒，不新增发送循环、不阻塞控制。发送队列拥堵仍可能丢失低频扩展。

上位机 `上位机/telemetry_v2.py` 同时支持RACE schema 1/2/3。请重新启动这个工作区中的上位机程序，以载入新解析器；旧上位机副本不认识schema 3。采集流程仍是协商、采集、停止、处理数据。

新增列保存于每组数据的 `.race.csv`：

| 字段 | 含义 |
| --- | --- |
| `acute_phase` | 0普通、1确认、2准备、3主弯、4出口观察 |
| `acute_reason` | 0无入口证据、1确认中、2准备中、3主弯接管、4余量不足、5S弯/锥桶优先、6证据丢失、7出口证据 |
| `acute_direction_code` | 0左弯、1无方向、2右弯 |
| `acute_position_mm` | 前轴处局部道路法向位置，向弯外为正 |
| `acute_goal_mm` | 本帧允许的向外位置目标，上限40 mm |
| `acute_feature_y_mm` | 可见弯墙特征位置，不能当真实弯口距离 |
| `acute_heading_rad` | 局部道路相对车辆的航向 |

位置、目标、距离、局部航向仅在阶段1/2作为有效测量使用，其他阶段不得将零值解释为“实际居中”或“距离为零”。按`session/control_seq/param_revision`关联；低频样本缺失不补值，旧schema缺字段在CSV中为空。

`PATH_EXTRA.road_target`、`road_error`保留准备前道路的含义；`target_x`是本帧实际跟踪目标。`outer_offset`在新准备阶段表示外侧目标分量，在普通分支仍是原远目标法向微调，都不是车辆实际横移。实际局部位置应看`acute_position_mm`。

也可在静态调试时发送 `acute` 按需读取一行，包含控制序号、有效性、阶段、原因、方向和位置量。此命令不是高频循环输出。

## 6. 实车核对重点

下一次在到达弯前开始正式采集，左右各测试，保留原好S弯、缓弯、直道与锥桶复测。主要查看阶段是否按1→2→3进入、位置是否开始向外变化、进入主弯时是否及时结束准备，以及出弯余量。若阶段始终0，应先看入口点云/原因，而不是继续盲目加大偏移。

40 mm上限及700/950 mm特征窗口需要实车校准。左右极限舵角/转弯半径、速度到毫米距离、全车实际外廓尚未标定；本次不能保证17/15下所有赛道无刮蹭，也没有把人工低速推车成功等同于高速自动成功。
