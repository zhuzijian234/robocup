## 修改内容与触发边界

### 1. 修正 T05 已复现的反向目标

`path_track.c / curve_handoff()`：上一有效帧使用曲线模型，当前单侧直线突然反向、没有可信远段时，额外复核本帧连续曲线。历史只触发复核，不直接指定舵机方向。

候选仍要通过原有唯一出口、轮廓连续性、逐段通路检查；还要求至少500 mm支持、与历史同向、近切线角差不超过0.35 rad、近参考距离差不超过120 mm、共同参考处中心差不超过100 mm。可靠双侧、有效远段、锥桶候选/避让、失效历史均不使用此补充分支。

新56份冻结云按同组、同修订、连续序号回放，序号缺口清状态，毫米量化云和统一83.333 ms间隔仅作同条件回归。T05 seq5825 在该回放条件下由反向直线改为 **右转曲线，目标x=+298.48 mm，PWM=1296**；镜像目标−298.48 mm、PWM1593。镜像将cx同时镜像为−10，用于检查几何和控制对称性，不是实车的新配置。

此前独立单帧复算得到+259.352 mm，使用实录宽522.075 mm和单独注入历史；本次连续回放保留前序量化云计算出的宽度与历史，故数值不同。两种方法均支持“存在通过本帧检查的同向曲线、旧分支却保留反向直线”的结论，不能将回放PWM当成实录PWM。

5826没有保存全点云；没有宣称复现完整闭环轨迹或证明修复后必能过弯。

### 2. 只在急弯入口内关联断开的墙

`acute_extension()` 只服务 `acute_wall()`，普通循迹及原曲线恢复的聚类规则保持原样。

近墙须先通过原近场拟合。远簇必须唯一、至少12点、前向跨度至少300 mm；真实墙端点距离不超过180 mm，前向位置在近墙端点−120～+150 mm内，偏离近切线法向范围受限。远簇近端150 mm需有同弯向切线，转角0.08～1.0 rad、法向均方根误差不超过20 mm。

关联只合并两簇真实点，不填补缺失分区。仍需三个连续50 mm分区偏离40 mm、连续200 mm有足够转角，仍拒绝反向/S形尾部、歧义出口和短小簇。准备目标继续接受实际点占用与局部通道检查；不将不可见区域宣称为已测空地。

T05原相邻数组簇距191～309 mm受中间孤立点影响；真正近墙端点到远墙入口约87～90 mm，因此不需要把全局聚类阈值放宽到310 mm。新函数可以关联T05、T03部分冻结云，但这些帧近墙角差或特征距离已到主弯条件，仍不布位。

**实测证据的限制：本批保存的56云仍没有进入PREPARE。** 不为使回放显示“成功”而放宽0.12 rad双墙角差、近墙分区数或700 mm接管门槛。新入口关联的更早介入已在断墙合成正例通过，实际提前量还需新采集；本次未扩展1.3 m外点云，因为原始快照没有那一段数据。

### 3. 外侧目标上限40→50 mm

`ACUTE_OUTER_MM=50` 表示相对局部中线、前轴参考的外侧位置上限。左弯向右准备，右弯向左准备；不逐帧累计，也不保证车身实际能达到50 mm。

仍按260 mm轮外宽、前轴到后轮外廓345 mm、当前姿态投影及40 mm几何余量裁剪。航向明显偏斜时上限会小于50 mm。连续两帧确认、950～700 mm混合回主路、主弯优先接管等规则保留；不拖延转向来凑满偏移量。

`acute_cones_clear()` 额外复核候选布位路径到已识别锥桶的底座包络距离，使用原170 mm底座包络、150 mm车辆半宽余量及|cx|。复核不调用有状态避桶函数，不会在一帧内推进两次确认。发生冲突取消新增布位，旧25 mm外移也不再叠回；正常避桶分支优先。

### 4. 诊断与采集

`ble_diag.c`：重复同值 `rate 1` 不再增加参数修订，避免采集协商清除转向历史。真正改变发送率仍沿用原修订机制；实际控制参数修改的重建行为保留。

新增 EVENT code 3，60字节总帧长。8槽队列由主循环写入和发送，不等待串口；满队列丢弃新事件并计数。阶段/方向/修订变化逐控制帧记录，仅原因/检查位变化最多每4控制帧抽样一次。正常输出稳定时不周期发送此事件。队列发送失败保留重试，前提是仍在当前会话；切换tele/session清队列。

这并不保证蓝牙端零漏采。`acute_event_dropped`统计固件事件队列溢出；传输后的缺失还要结合tx_seq缺口等判断。暂停或断开会话后的未送达事件不能假定已到PC。

阶段事件在CONTROL的rate抽样前捕获。时间为**事件发生时设备毫秒**，并携带控制序号、输入序号、修订。PC导出同名前缀 `.acute.csv`；不要按host接收时间或视频结束时间硬对齐。

第一次入口CONFIRM新增点云触发位128：已有至少3个有效控制帧时，保留触发前两帧、触发帧、后一帧。仍是“首次4帧+末段4帧”，每帧最多400点，不增加整圈点云缓冲，不在行驶时流式发送全云。已有更早异常先触发时仍保留该首次异常。

## 协议登记

CONTROL、PATH、RACE schema 3 的长度和字段偏移不变。CLOUD升至schema 4，允许trigger_flags位128；PC同时接受旧schema 1/2/3。

EVENT code 3 的payload：先为 `<IIHH>`，分别是event_ms、param_revision、code=3、body_size=32；body为 `<8I>`：

| 索引 | 字段 | 含义 |
|---|---|---|
| 0 | schema | 固定1 |
| 1 | control_seq | 发生时的控制序号 |
| 2 | input_seq | 输入扫描序号 |
| 3 | acute_phase | 0原循迹、1确认、2准备、3主弯、4出口 |
| 4 | acute_reason | 沿用RACE的0～7枚举 |
| 5 | acute_direction_code | 0左弯、1无、2右弯 |
| 6 | acute_checks | 下表位图，可同时置多位 |
| 7 | acute_event_dropped | 本次队列生命周期内事件溢出累计 |

| acute_checks值 | 含义 |
|---|---|
| 1 | 近墙不足或墙身份不独立 |
| 2 | 两近墙切线角差超限 |
| 4 | 没有唯一急弯方向 |
| 8 | 弯特征已近或航向达到接管条件 |
| 16 | 通道宽度、姿态、余量或可见通路不满足准备 |
| 32 | S弯、反向证据或正在避桶优先 |
| 64 | 近墙提前结束，进行了延续关联检查；不等于已证明缺墙 |
| 128 | 找到唯一受约束的远墙延续；不等于允许进入准备 |
| 256 | 候选布位路径与已识别锥桶底座包络冲突 |
| 512 | 远线预筛不满足，或已有其它路径模型接管 |

例如checks=194=128+64+2：墙延续关联成功，但近墙角差超限，仍不允许准备。方向字段可以是候选方向，只有phase=2才表明布位实际接管。扫描失效产生的OFF/LOST结合PATH的geometry_reason/scan标志判断，不冒充“近墙不足”。

## 编译、内存与性能边界

Keil AC5，Cortex-M4.fp.sp，C99/O0，MicroLIB，项目m10p.sct，59个源码单元：**0错误、19条原有警告**。警告来自未修改的usart.c、bsp_bluetooth.c及旧测试中文编码；本轮生产修改无新增警告。

- ROM：62,028字节。
- 普通SRAM：79,472字节，包含4,096字节栈及512字节堆，比r2的79,240增加232字节。128 KiB普通SRAM余51,600字节，未依赖CCM放置DMA。
- DMA地址：`0x200001e8`，仍在普通SRAM。
- 静态已知最大栈深2,272字节，配置4,096字节；相较r2增加320字节。链接器仍标有间接调用/循环未知项，中断嵌套与实际栈水位要上板测量，不能把静态数值当绝对最坏值。
- 额外曲线复核只在严格的异常模型交接场景触发；断墙关联只在急弯入口预筛通过后执行；没有全局平滑、额外扫描周期或等待串口。
- 新事件通常仅阶段变化发送，每帧60字节，12 Hz持续变阶段的理论附加量约720 B/s，原因位单独变化最多约180 B/s。实际固件处理时间与蓝牙拥塞须观察`process_us/process_max_us`、tx缺口及事件丢弃计数，尚无本版实车耗时测量。

## 下一轮采集

烧录本页固件并重开当前上位机，保持17/15、cx10。用原来V2采集流程，停止后等待点云导出和报告完成。保存BIN、meta、CSV、`.race.csv`、`.acute.csv`、`.path.csv`、`.cloud_frames.csv`、`.cloud.csv`以及原视频；拍摄与采集从同一可见动作起点开始。

优先观察左/右急弯：是否在主弯前出现连续CONFIRM→PREPARE，目标是否受姿态限幅，是否保持向外位置收敛并及时接回主弯，是否仍有目标反向或外侧擦碰。重复左右后复测直道、长缓弯、连续S弯及左右各摆桶。

若checks长期为1/2/8，先判断当时是否已经太靠近主弯；不能只增大偏移。若512且视频显示远处入口，则需要更早的点云或独立远区采集，才有依据研究1.3 m以外。未有效进入PREPARE前，不据此增加至60～100 mm，也不降低700 mm接管门槛拖延转弯。

本版是有明确反向目标修复、限定入口识别增强及可诊断布位的试车版本；离线回归支持已覆盖场景的保留，无法保证所有未知赛道摆放和高速车身动力学表现。
