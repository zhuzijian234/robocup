# M10P 最近一次大弯修改回退

日期：2026-10-13。用户反馈最近一轮大弯效果不理想，要求回退该轮修改。

## 回退范围

最近一次控制改动为 `1b98d3b（大弯2）`。其前一个提交 `7ee733b` 只补充测试资料，控制代码与 `3c1af22` 相同。本次将转向恢复至 `3c1af22` 的 r2 版本，没有重置 Git 历史，也没有删除测试视频、遥测或历史固件。

以下三个生产文件已逐文件核对，与 `3c1af22` 一致：

- `HARDWARE/CENTRE_LINE/CENTRE_LINE.c`
- `HARDWARE/CENTRE_LINE/path_track.c`
- `HARDWARE/CENTRE_LINE/path_track.h`

具体撤回：新增曲线交接复核 `curve_handoff()`、急弯断墙关联 `acute_extension()`、额外布位桶底座复核及对应调用、急弯检查位字段。外侧位置上限从50 mm恢复40 mm。原r2提前布位、主弯接管、普通弯、S弯和原有避桶逻辑保留。

配套撤回车端新增急弯阶段事件队列及CONFIRM点云触发，恢复CLOUD schema 3；RACE仍为schema 3。删除仅适用于被撤回事件功能的测试，更新新批次点云回归，使其核对所有结果恢复r2，包括此前T05的旧输出。回退是恢复既有行为，不表示此前所有急弯问题已经解决。
