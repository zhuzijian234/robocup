# M10P 蓝牙上位机使用说明

更新日期：2026-10-13。适用当前 M10P 竞速固件，使用现有的 V2 遥测及 `spd` 命令。本次仅修改电脑上位机，无须为这次界面更新重新烧录固件。

## 启动与连接

1. 关闭原来的上位机，双击本目录的 `启动上位机.bat`。
2. 选择已配对 HC-05 的传出 COM 口，波特率默认 115200，点击“连接”。不要让串口助手等其他程序同时占用该 COM 口。
3. 连接本身不会改变电机目标速度。

## 常用操作

| 按钮 | 行为 |
| --- | --- |
| 一键检测并启动电机 / F5 | 先完成 V2 会话、协议及配置协商，再按“启动速度”启动电机并采集。协商失败不会执行这次自动启动。 |
| 启动电机 | 独立发送启动速度，无须开始遥测采集。默认 17，可输入 1～18 的整数。 |
| 关闭电机 | 发送 `spd 0`，并取消尚未执行的自动启动。采集、点云导出和报告生成期间均可使用。 |
| 停止采集 | 提前结束记录，自动保存、导出冻结点云并生成报告；**不会关闭电机**。 |
| 打开报告 / 打开数据目录 | 查看最近报告，或进入本目录的 `log` 文件夹。 |
| 处理已有 BIN | 选择之前保存的原始数据，重新生成报告。 |

启动速度设置的是固件的速度上限，并非 PWM 占空比或 km/h；弯道目标仍由车端现有控制算法计算。上位机没有修改车端弯道参数。

检测时长默认 30 秒，到时与手动“停止采集”一样结束记录。记录结束后点云导出可能还需要最多 24 秒，随后生成报告。期间不显示实时曲线，仅显示收帧、字节数和采样车速。任务完成后串口保持连接，可以直接再次检测。

## 启停确认与中途取消

- 显示“等待启动/关闭确认”表示命令仍待确认；收到车端对应的 `OK spd=...` 才显示“指令已确认”。这表示车端接受了目标，不等于独立测得电机已经转动或停止。
- 命令未收到确认时会有限重试；最终仍无回复时显示“指令未确认”，操作记录保留原因。
- 协商期间点击“关闭电机”会取消本次协商，然后在同一连接上发送关闭命令；不会在协商结束后又自动启动。
- 仅点击“停止采集”也会取消本次尚未执行的自动启动；已经运行的电机保持当前目标。
- 断开连接或关闭窗口不等于关闭电机。需要停电机时先点红色“关闭电机”，查看车端确认。关闭窗口会结束采集并保存已有数据，可能取消尚未完成的点云导出。

## 保存与交付数据

每次采集在 `log` 中生成独立文件名，自动保存 `.bin`、`.bin.rx.jsonl`、`.bin.meta.json`，并生成 CSV、报告和可用图表。分析时应一起保留前三份原始文件。

协商失败、会话变化或通信错误时仍保留已经收到的数据并尝试生成报告；“生成了报告”不代表本次采集完整成功，应同时检查界面状态、操作记录和报告中的结束原因。
