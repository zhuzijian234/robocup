# 雷达循线小车 — 数据流详解文档

> 从雷达原始字节到舵机/电机PWM输出的完整数据链路。

---

## 总览：三大阶段

```
┌─────────────────────────────────────────────────────────────┐
│ 阶段一: 硬件传输层                                           │
│   雷达 → USART6 → DMA → 内存                                │
│   CPU 零参与，全硬件自动                                     │
├─────────────────────────────────────────────────────────────┤
│ 阶段二: 感知层 (LEIDA_DATA.c)                                │
│   原始字节 → 极坐标 → 筛选 → 边界 → 中线 → 前视 → 断点       │
├─────────────────────────────────────────────────────────────┤

│   模式选择 → PD/PID计算 → 舵机PWM + 电机PWM                  │
└─────────────────────────────────────────────────────────────┘
```

# 阶段一：硬件传输层（CPU 零参与）

## 1.1 物理层

```
LD14P 激光雷达
    │
    │  TX 引脚输出串口数据 (230400bps, 8N1)
    │  每帧 47 字节，每秒约 60 帧
    │
    ↓ 导线
    │
STM32F407 PC7 引脚 (USART6_RX)
```

### 涉及的函数

| 步骤 | 函数 | 文件 | 作用 |
|------|------|------|------|
| 初始化 | `uart6_init(230400)` | [usart.c:158](SYSTEM/usart/usart.c#L158) | 配置 PC6/PC7 为 USART6, 230400bps |
| 初始化 | `DMA_Initializes()` | [DMA.c:25](HARDWARE/DMA/DMA.c#L25) | 配置 DMA2 Stream1 Ch5 |

## 1.2 DMA 自动搬运

```
USART6 硬件每收一个字节:
  USART6->DR ← 收到的字节
        │
        ↓ (硬件自动触发 DMA 请求, CPU 不知道)
        │
  DMA2_Stream1_Channel5:
    源地址: &USART6->DR (固定不变)
    目标地址: DMA_USART6_RX_BUF[0] → [1] → [2] → ... → [1999]
    每次传输后目标地址自动 +1
        │
        ↓ (2000 字节传完)
        │
  DMA 传输完成中断 → DMA2_Stream1_IRQHandler()
    ├── memcpy(DMA_USART6_RX_BUF_r, DMA_USART6_RX_BUF, 2000)  ← 双缓冲安全拷贝
    ├── DMA_RX_DONE = 1    ← 通知主循环
    └── 重新使能 DMA       ← 准备接收下一帧
```

### 涉及的全局变量

| 变量 | 定义文件 | 含义 |
|------|---------|------|
| `DMA_USART6_RX_BUF[2000]` | [DMA.c:20](HARDWARE/DMA/DMA.c#L20) | DMA 直接写入的缓冲区 |
| `DMA_USART6_RX_BUF_r[2000]` | [DMA.c:21](HARDWARE/DMA/DMA.c#L21) | 双缓冲安全拷贝，主循环读取 |
| `DMA_RX_DONE` | [DMA.c:22](HARDWARE/DMA/DMA.c#L22) | 一帧就绪标志（=1 通知主循环） |

### 关键点

- **2000 字节 ≠ 一帧**。一帧 47 字节，2000 字节大约 42 帧的数据，DMA 攒一大包再通知 CPU。
- CPU 在整个传输过程中完全不知情，等传完了才收到一次中断。
- 双缓冲 (`DMA_USART6_RX_BUF` + `DMA_USART6_RX_BUF_r`) 保证主循环读数据时 DMA 不会覆盖。

## 2.1 HANDLE1 — 原始字节 → 极坐标

**函数**: `LEIDA_DATA_HANDLE1()` @ [LEIDA_DATA.c:63](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L63)

```
输入: DMA_USART6_RX_BUF_r[2000] (原始字节流)
输出: LEIDA_DATA[800] (极坐标: 角度° + 距离mm)

处理步骤:
  1. 找同步: 搜索间隔47字节的3个连续 0x54 帧头
  2. 逐帧解析:
     每帧47字节 → 12个数据点
     ├── byte[4-5]: 起始角度/100 = 度
     ├── byte[6+3k, 7+3k]: 距离 (低字节在前) → u16 → mm
     ├── 角度 = 起始 + (结束-起始)/12 × k  (线性插值)
     ├── 角度归一化到 [0°, 360°)
     └── 角度旋转+90°: 0°=右侧(x+), 90°=前方(y+), 180°=左侧(x-)
```

### 角度坐标系（旋转后）

```
             90° (正前方 y+)
               ↑
               |
  180° ←────── 车 ──────→ 0°/360° (右侧 x+)
  (左侧 x-)
```

## 2.2 HANDLE3_2 — 筛选有效点

**函数**: `LEIDA_DATA_HANDLE3_2()` @ [LEIDA_DATA.c:183](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L183)

```
输入:  LEIDA_DATA[800] (全部解析点)
输出:  LEIDA_DATA2[]   (有效点)
返回:  valid_couter    (有效点个数)

筛选条件:
  ├── 距离 >= 100mm  (过滤雷达自身反射等近场噪声)
  └── 掐头去尾各10个点 (过滤数组两端不稳定数据)
```

## 2.3 LEIDA_Distance — 跑道宽度计算

**函数**: `LEIDA_Distance()` @ [LEIDA_DATA.c:498](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L498)

```
输入:  LEIDA_DATA2[]
输出:  paodao_distance (mm)

算法:
  1. 对每个左半区点 (150°~210°)，找对面 (angle+180°) 的配对点
  2. 距离和 = 左点距离 + 右点距离
  3. 用6元素最小级联，取第6小的距离和作为跑道宽度
     (取第6小而非最小，避免个别噪点影响)
```

## 2.4 HANDLE6 / HANDLE7 — 左右边界提取

**函数**: `LEIDA_DATA_HANDLE6()` @ [LEIDA_DATA.c:341](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L341)
        `LEIDA_DATA_HANDLE7()` @ [LEIDA_DATA.c:381](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L381)

```
输入:  LEIDA_DATA2[]
输出:  LEIDA_DATA_LEFT[]  (LEFT_cnt 个点)
       LEIDA_DATA_RIGHT[] (RIGHT_cnt 个点)

算法:
  HANDLE6 (左边界):
    从 180°(左侧) 向下扫描 LEIDA_ANGLE_resolution 度
    每个角度步进找第一个距离<=4000mm 的点

  HANDLE7 (右边界):
    从 0°(右侧) 向上扫描 LEIDA_ANGLE_resolution 度
    每个角度步进找第一个距离<=4000mm 的点
    处理 0°/360° 角度回绕
```

## 2.5 HANDLE5 / HANDLE5_2 — 前方路径扫描

**函数**: `LEIDA_DATA_HANDLE5()` @ [LEIDA_DATA.c:588](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L588)
        `LEIDA_DATA_HANDLE5_2()` @ [LEIDA_DATA.c:669](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L669)

```
HANDLE5: 前方 (70°~110°) 扫描

  1. 空旷检测: 正前方 (86°~94°) 有 >=5 个点距离 >1.5m
     → 认为前方无遮挡，返回 0 (不需要前视数据)

  2. 否则前方有墙:
     70°~110°, 步进1°, 每度找最近有效点
     → LEIDA_DATA_Forward[] (Forward_cnt 个点)
     → 最小二乘拟合 → Midline_forward (斜率k, 截距b)
     → 按y间距滤除离群点

HANDLE5_2: 侧前方扫描 (S弯检测)
  → LEIDA_DATA_Forward_2[] (70°~90°, 右侧前方)
  → LEIDA_DATA_Forward_3[] (90°~110°, 左侧前方)
```

## 2.6 HANDLE8 / HANDLE9 — 边界突变检测（弯道入口）

**函数**: `LEIDA_DATA_HANDLE8()` @ [LEIDA_DATA.c:435](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L435)
        `LEIDA_DATA_HANDLE9()` @ [LEIDA_DATA.c:465](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L465)

```
输入:  LEIDA_DATA_LEFT[] / LEIDA_DATA_RIGHT[]
输出:  断点y坐标 (mm), 无突变返回0

算法: 6点滑动窗口三重判定
  同时满足才认为是真突变:
    |dist[i]   - dist[i+1]| >= 400mm  AND
    |dist[i-1] - dist[i+2]| >= 400mm  AND
    |dist[i-2] - dist[i+3]| >= 400mm

  HANDLE8: 仅检测左侧 (角度>=100°)
  HANDLE9: 仅检测右侧 (角度<=80°)

返回值: 突变点距车最近一侧的y投影距离 (1m以内有效)
```

## 2.7 HANDLE4 — 中线点计算

**函数**: `LEIDA_DATA_HANDLE4()` @ [LEIDA_DATA.c:232](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L232)

```
输入:  LEIDA_DATA2[] (有效极坐标点)
输出:  LEIDA_DATA_CENTER[] (中线点, CENTER_cnt 个)

算法:
  1. 对称角度扫描: 右0°→75°, 左180°→105°, 步进0.6°
  2. 每对角度找最近的左右配对点
  3. 中点坐标 = (左点笛卡尔 + 右点笛卡尔) / 2
  4. 排除x最大/最小各2个离群点
  5. 按相邻点x间距一致性滤除
  6. 只保留 y <= 800mm 的近区点
```

## 2.8 HANDLE11 — 中线垂直度判断

**函数**: `LEIDA_DATA_HANDLE11()` @ [LEIDA_DATA.c:865](HARDWARE/LEIDA_DATA/LEIDA_DATA.c#L865)

```
输入:  LEIDA_DATA_CENTER[]
输出:  中线x坐标 (垂直情况下), 0 (不垂直)

判断: 3级x极值跨度 < 10mm → 垂直 (直道)
     否则 → 不垂直 (弯道或中线歪斜)
```

## 3.2 转向控制: Midline_PD()

**函数**: `Midline_PD()` @ [CENTRE_LINE.c:254](HARDWARE/CENTRE_LINE/CENTRE_LINE.c#L254)

```
输入:
  centerline[]     → 用于计算偏差的点集 (前视/中线/边界)
  midline->k, ->b  → 拟合直线参数
  pid_select       → 控制模式 (0~9)
  Servo_pd         → PID参数块 (三组 kp/kd)

处理:
  1. 根据 pid_select 计算偏差:
     pid=0:  err = -(中线末点x偏离50mm的量)
     pid=1:  err = -(沿右边界走 + 宽度补偿)
     pid=2:  err = -(沿左边界走 - 宽度补偿)
     pid=3,4,8,9: err = -Δy/k (前视方向偏差)
     pid=5:  err = -(中线垂直x - 50)
     pid=6,7: err = -中线均值

  2. 偏差限幅 [-500, 500]

  3. PD控制:
     servo_pwm = 中位 + kp*err + kd*(err - err_last)   ← 哪个kp/kd看pid_select

  4. 缩放 ×10 + 限幅 [1360, 1800] → 舵机PWM

输出:
  舵机 PWM 值 (1360~1800)
  Servo_ChangePwm() → TIM_SetCompare1(TIM3, pwm) → PA6 引脚
```

**涉及文件**: [Servo.c:13-21](HARDWARE/Servo/Servo.c)

```
Servo_Init(84, 20000, servo_midpwm)
  → TIM3_PWM_Init(83, 19999, puse)  @ PWM.c:169
    → PA6 = AF2, PWM 50Hz

Servo_ChangePwm(servo_pwm)
  → TIM_SetCompare1(TIM3, servo_pwm) → TIM3->CCR1 = servo_pwm
    → 舵机转角改变
```

## 3.3 速度控制（独立并行回路）

速度控制**不在主循环里**，而是由 **TIM5 10ms 中断**独立运行：

**ISR**: `TIM5_IRQHandler()` @ [timer.c:84](HARDWARE/LEIDA_TIMER/timer.c#L84)

```
每10ms自动触发:
  1. Get_Encoder()           @ moto.c:76
     ├── 读 TIM4->CNT (正交编码器计数值)
     ├── 5采样滑动平均去噪
     └── Speed_now = (EncoderCNT×100) / (4×11×6.25)

  2. PID_realize()           @ CENTRE_LINE.c:403
     ├── err = Speed_mubiao - Speed_now
     ├── 位置式PI: pwm = kp×err + ki×Σerr + kd×Δerr
     └── 输出限幅 [0, 100]

  3. Moto_Speed(moto_pwm)    @ moto.c:47
     └── TIM_SetCompare3(TIM2, moto_pwm) → TIM2->CCR3 = moto_pwm
```

**涉及文件**:

|------|------|------|
| `TIM5_Int_Init()` | [timer.c:22](HARDWARE/LEIDA_TIMER/timer.c#L22) | 84M/8400=10kHz, 周期100→10ms |
| `TIM5_IRQHandler()` | [timer.c:84](HARDWARE/LEIDA_TIMER/timer.c#L84) | 中断服务函数 |
| `Encoder_Init()` | [moto.c:52](HARDWARE/moto/moto.c#L52) | TIM4 正交编码器 |
| `Get_Encoder()` | [moto.c:76](HARDWARE/moto/moto.c#L76) | 读编码器+计算速度 |
| `PID_realize()` | [CENTRE_LINE.c:403](HARDWARE/CENTRE_LINE/CENTRE_LINE.c#L403) | 位置式PI |
| `Moto_Speed()` | [moto.c:47](HARDWARE/moto/moto.c#L47) | 写 PWM CCR3 |
| `Moto_Init()` | [moto.c:20](HARDWARE/moto/moto.c#L20) | PE4/PE5 方向控制 + TIM2 CH3 PWM |

# 完整数据流时间线

```
时间轴 →

T0: 硬件自动
    USART6 逐位收数据 → DR寄存器 → DMA 搬进内存 → 2000字节满 → 中断

T1: DMA中断 (DMA2_Stream1_IRQHandler)
    双缓冲拷贝 → DMA_RX_DONE=1

T2: 主循环检测到 DMA_RX_DONE  @ main.c:153
    │
    ├── HANDLE1  原始字节→极坐标  LEIDA_DATA[800]
    ├── HANDLE3_2 筛选有效点     LEIDA_DATA2[]
    ├── LEIDA_Distance 跑道宽度  paodao_distance
    ├── HANDLE6/7 左右边界      LEIDA_DATA_LEFT[]/RIGHT[]
    ├── HANDLE5   前方扫描      LEIDA_DATA_Forward[] + Midline_forward
    ├── HANDLE8/9 断点检测      LEFT_duandian / RIGHT_duandian
    │
    ├── 模式决策 (pid_select = 0~9)
    ├── Midline_PD() → 舵机 PWM
    └── ↻ 循环

    (并行，独立于主循环)

T2+0ms:  TIM5 中断 #1 → 读编码器 → PI → 更新电机 PWM
T2+10ms: TIM5 中断 #2 → ...
T2+20ms: TIM5 中断 #3 → ...
...
```

速度控制每 10ms 稳定执行一次，与主循环完全解耦。主循环处理完一帧雷达数据后更新舵机角度，耗时取决于数据量和计算复杂度（通常 < 5ms）。
