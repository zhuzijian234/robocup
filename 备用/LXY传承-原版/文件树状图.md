# 项目文件树状图

```
robo_s弯（调参数）/
│
├── USER/
│   ├── main.c                          【主程序】初始化 + 主循环 + 多模式转向决策
│   ├── stm32f4xx.h                      STM32F4 寄存器定义（库文件）
│   ├── stm32f4xx_conf.h                 外设配置头（库文件）
│   ├── stm32f4xx_it.c/h                 中断服务函数模板（库文件）
│   └── system_stm32f4xx.c/h             系统时钟配置（库文件）
│
├── HARDWARE/
│   │
│   ├── CENTRE_LINE/                     【核心】中线检测 + PID控制
│   │   ├── CENTRE_LINE.h                数据结构：Midline_type(y=kx+b)、pid_type
│   │   │                                函数声明：Midline_fit/Midline_PD/PID_realize 等
│   │   └── CENTRE_LINE.c                实现：
│   │                                       ├─ Midline_fit()        最小二乘法直线拟合
│   │                                       ├─ Midline_PD()         9模式PD舵机控制器
│   │                                       ├─ PID_realize()        位置式PI速度控制器
│   │                                       ├─ Speed_PID()          增量式PD速度控制器(备用)
│   │                                       ├─ curvity_cal()        三点法曲率计算
│   │                                       └─ Midline_PD_Init() / Speed_PID_Init()  参数初始化
│   │
│   ├── LEIDA_DATA/                      【核心】雷达数据处理流水线
│   │   ├── LEIDA_DATA.h                数据结构：_LEIDA_DATA(极坐标)、_LEIDA_DATA_plane(笛卡尔)
│   │   │                                宏定义：LEIDA_ANGLE_RIGHT/LEFT/CENTER 等
│   │   │                                函数声明：13个HANDLE + LEIDA_Distance + 调试打印
│   │   └── LEIDA_DATA.c                实现：
│   │                                       ├─ HANDLE1()   解析47字节数据包 → 极坐标
│   │                                       ├─ HANDLE2()   极坐标 → 笛卡尔坐标(x,y)
│   │                                       ├─ HANDLE3()   筛选左右90°内有效点
│   │                                       ├─ HANDLE3_2() 筛选距离≥100mm有效点
│   │                                       ├─ HANDLE4()   配对左右边界 → 中线中点
│   │                                       ├─ HANDLE5()   前方70-110°路径扫描+障碍检测
│   │                                       ├─ HANDLE5_2() 指定角度前方扫描(S弯检测用)
│   │                                       ├─ HANDLE6()   提取左边界(180°→90°)
│   │                                       ├─ HANDLE7()   提取右边界(0°→90°)
│   │                                       ├─ HANDLE8()   左边界突变检测(弯道入口)
│   │                                       ├─ HANDLE9()   右边界突变检测(弯道入口)
│   │                                       ├─ HANDLE10()  边界离群点滤除
│   │                                       ├─ HANDLE11()  中线垂直度判断(直道检测)
│   │                                       ├─ HANDLE12()  占位函数(预留)
│   │                                       ├─ HANDLE13()  边界直线度判断
│   │                                       ├─ LEIDA_Distance()  跑道宽度(左右距离对第6小值)
│   │                                       ├─ LEIDA_ANGLE_jiuzheng()  雷达角度校准
│   │                                       ├─ reverse()   数组反转
│   │                                       └─ LEIDA_PrintAll/Sample/Head()  调试打印
│   │
│   ├── moto/                            【驱动】电机 + 编码器
│   │   ├── moto.h                       函数声明
│   │   └── moto.c                       实现：
│   │                                       ├─ Moto_Init()      电机PWM + 方向引脚初始化
│   │                                       ├─ Moto_Speed()     设置电机占空比(TIM2 CCR3)
│   │                                       ├─ Encoder_Init()   编码器初始化(TIM4)
│   │                                       └─ Get_Encoder()    5采样滑动平均 → Speed_now
│   │
│   ├── Servo/                           【驱动】舵机
│   │   ├── Servo.h                      函数声明
│   │   └── Servo.c                      实现：
│   │                                       ├─ Servo_Init()        舵机PWM初始化(TIM3)
│   │                                       └─ Servo_ChangePwm()   修改舵机角度(TIM3 CCR1)
│   │
│   ├── LEIDA_TIMER/                     【驱动】速度控制定时器
│   │   ├── timer.h                      函数声明 + 倒车标志/编码器标志
│   │   └── timer.c                      实现：
│   │                                       ├─ TIM5_Int_Init()    10ms定时中断初始化
│   │                                       ├─ TIM14_Int_Init()   辅助定时器(预留)
│   │                                       └─ TIM5_IRQHandler()  中断服务: 读编码器→PI→更新电机
│   │
│   ├── DMA/                             【驱动】雷达串口DMA接收
│   │   ├── DMA.h                        宏: DMA2_Stream1_IQ_ENABLE, DMA_USART6_RX_BUF_LEN=2000
│   │   └── DMA.c                        实现：
│   │                                       ├─ DMA_Initializes()           DMA2 Stream1初始化
│   │                                       └─ DMA2_Stream1_IRQHandler()   传输完成中断: 双缓冲+通知主循环
│   │
│   ├── LEIDA_PWM/                       【驱动】雷达电机转速PWM
│   │   ├── leida_pwm.h                  函数声明
│   │   └── leida_pwm.c                  实现：
│   │                                       ├─ LEIDA_PWM_Init()   TIM1 CH4 (PA11) 雷达电机PWM
│   │                                       └─ TIM9_PWM_Init()    TIM9 CH1 (PE5) 通用PWM
│   │
│   ├── BLUE/                            【驱动】蓝牙(已弃用 → 被hc-05替代)
│   │   ├── BLUE.h                       旧蓝牙头文件
│   │   └── BLUE.c                       占位文件, #if 0 禁用
│   │
│   ├── hc-05/                           【驱动】HC-05蓝牙模块
│   │   ├── board.h                      板级引脚占位定义
│   │   ├── bsp_bluetooth.h              宏: USART3引脚/时钟/波特率/连接状态
│   │   └── bsp_bluetooth.c              实现：
│   │                                       ├─ Bluetooth_GPIO_Init()      USART3 GPIO初始化
│   │                                       ├─ BLE_Send_Bit()             发送单字符
│   │                                       ├─ BLE_send_String()          发送字符串
│   │                                       ├─ Clear_BLERX_BUFF()         清空接收缓冲
│   │                                       ├─ Bluetooth_Link_Gpio_Init() STATE引脚初始化
│   │                                       ├─ Bluetooth_Init()           蓝牙总初始化
│   │                                       ├─ Get_Bluetooth_ConnectFlag() 查询连接状态
│   │                                       ├─ Bluetooth_Mode()           轮询STATE引脚
│   │                                       ├─ Receive_Bluetooth_Data()   处理接收数据
│   │                                       ├─ Send_Bluetooth_Data()      发送数据到手机
│   │                                       └─ BSP_BLUETOOTH_IRQHandler() 中断服务(RXNE+IDLE)
│   │
│   ├── TIM/                             【驱动】定时器PWM集合
│   │   ├── PWM/
│   │   │   ├── PWM.h                    函数声明: PWM_Init_leida/TIM2~4/TIM10~11
│   │   │   └── PWM.c                    实现：
│   │   │                                   ├─ TIM10_PWM_Init()  TIM10 CH1 (PF6) PWM
│   │   │                                   ├─ TIM11_PWM_Init()  TIM11 CH1 (PB9) PWM
│   │   │                                   ├─ TIM2_PWM_Init()   TIM2 CH3 (PA2) 电机PWM
│   │   │                                   ├─ TIM3_PWM_Init()   TIM3 CH1 (PA6) 舵机PWM
│   │   │                                   ├─ TIM4_PWM_Init()   TIM4 编码器模式
│   │   │                                   ├─ PWM_Init_leida()  TIM9 CH2 (PE6) 雷达电机PWM
│   │   │                                   └─ PWM_SetCompare_leida()  修改雷达电机占空比
│   │   │
│   │   ├── PWM1/
│   │   │   ├── PWM.h                    函数声明: TIM2/TIM3 (无pulse参数版)
│   │   │   └── PWM.c                    实现：简化版PWM, 初始脉宽固定1050
│   │   │                                   ├─ TIM2_PWM_Init()   TIM2 CH1 (PA2)
│   │   │                                   └─ TIM3_PWM_Init()   TIM3 CH1 (PA6)
│   │   │
│   │   ├── PWM_pn_out/
│   │   │   ├── PWM_pn_out.h             函数声明: TIM1互补PWM
│   │   │   └── PWM_pn_out.c             实现：TIM1 CH1(PA8)+CH1N(PA7)互补输出, 死区~3µs
│   │   │
│   │   └── TIM/
│   │       ├── TIM.h                    函数声明: TIM14 + 800点正弦查找表(SPWM)
│   │       └── TIM.c                    实现：TIM14中断定时器(预留SPWM)

│
├── DSP/                                 CMSIS-DSP库（ARM官方数学库）
│   ├── arm_math.h                       主头文件
│   ├── arm_common_tables.h              三角函数查找表
│   └── arm_const_structs.h              常数结构体
│
├── CORE/                                CMSIS内核文件（ARM官方）
│   ├── core_cm4.h                       Cortex-M4 内核定义
│   ├── core_cm4_simd.h                  SIMD指令
│   ├── core_cmFunc.h                    内核函数
│   ├── core_cmInstr.h                   内核指令
│   └── startup_stm32f40_41xxx.s         启动文件(汇编)
│
├── FWLIB/                               STM32F4标准外设库（ST官方）
│   ├── inc/                             头文件: gpio/tim/usart/dma/rcc 等
│   └── src/                             源文件: gpio/tim/usart/dma/rcc 等
│
├── SYSTEM/                              系统组件
│   ├── delay/delay.c/h                  延时函数(微秒/毫秒)
│   ├── sys/sys.c/h                      系统时钟/位带操作
│   └── usart/usart.c/h                  串口1调试输出(printf重定向)
│
└── 架构说明.md                          本文档 — 项目架构与各文件作用说明
```

robo_s弯（调参数）/HARDWARE/

├── CENTRE_LINE.c/h  ───  🧠 大脑：算中线、做PID、控制舵机

├── moto.c/h         ───  🦵 左腿：电机驱动、编码器测速
├── Servo.c/h        ───  🦵 右腿：舵机转向

│
├── DMA.c/h          ───  📡 天线：高速接收雷达数据
├── LEIDA_PWM/       ───  🔄 旋转：控制雷达自身电机转速
│
├── hc-05/           ───  📱 遥控：蓝牙连手机，调参看数据
│
├── TIM/PWM/         ───  ⚙️ 底层：PWM/编码器的硬件初始化代码
├── TIM/PWM1/        ───  ⚙️ 底层：PWM变体（固定初始值）
├── TIM/PWM_pn_out/  ───  ⚙️ 底层：互补PWM+死区（预留）
└── TIM/TIM/         ───  ⚙️ 底层：SPWM正弦波定时器（预留）
