## 3. 八个视频的共同点（可见事实）

1. **每个视频开头都有人手在车旁**（起步放手）
2. **每个视频结尾都有人的手/脚入镜**，且镜头转为车轮/车体/管子的**特写** → 车停下后人来查看
3. **地面**：浅色抛光地面 + 一条**黑色胶带条**（多次出现在画面里，可作位置参照）
4. **边界**：银白色**波纹软管**
5. **锥桶**：本批抽样帧里**只在 01 的 f0195（6.50s）看到一次红色锥桶**；其余七个视频的抽样帧没有锥桶
6. 摄像机全程**手持、竖屏**（除 04 是横屏）

## 4. 看不出 / 无法确认（诚实边界）

1. **前轮实际转角**：车在画面里太小、且多为俯视/后视，**看不清前轮偏转**。
   所以 05 的"舵机几乎没动"是**用户观察**，我无法从画面证实或否证。
2. **是否真的"接触"**：全景区分不出"紧贴"和"接触"。
   我只在**能明确看到车体/车轮与管子重叠或顶住**时才标 `CAR-AT-TUBE`；
   04 和 08 我没有标接触（不是否定，是**看不出来**）。
3. **弯道半径、通道宽度、管子直径**：无标尺参考 + 手持透视，**测不了**。
4. **车的绝对轨迹与速度**：摄像机在动，**无法还原**。
5. **视频时间与遥测时间的对应**：本文件**没有做对齐**。

## 6. 复现命令

```powershell
$py='D:\anaconda3\anaconda3\python.exe'
$R='D:\OneDrive\Desktop\robocup\调试视频\视频解析_AI可读_20261010_二批'
& $py -B "$R\extract.py"    # 抽帧 + overview.jpg
& $py -B "$R\mark.py"       # overview_marked.jpg（标记色框）
```

**踩过的坑**：Windows 下 `cv2.imread` / `cv2.imwrite` 对**中文路径会失败**（`imread` 返回 `None`、`imwrite` 静默失败）。
本目录脚本一律用 `cv2.imdecode(np.fromfile(...))` 读、`cv2.imencode(...)[1].tofile(...)` 写。
另外 `cv2.putText` 的 Hershey 字体**不支持中文**，图内文字必须用 ASCII。
