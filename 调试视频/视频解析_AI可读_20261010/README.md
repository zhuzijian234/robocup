**给 AI 读的入口**：先读 `sheets\overview_marked.jpg`（一张图 = 20 帧 + 标记），
需要细节再读 `frames\` 里的单帧（文件名就是原片帧号）。
**图内文字是 ASCII**（`cv2.putText` 的 Hershey 字体不支持中文），中文事实见本文件。

标记颜色（`overview_marked.jpg` 顶部也写明了）：

| 颜色 | 含义 |
|---|---|
| 橙 `orange / CONE` | 画面里出现**红色锥桶** |
| 红 `red / CAR-TOUCH-TUBE / STOPPED` | **车与管壁接触/紧贴**，或**车停住不再移动** |
| 青 `cyan / CURVE` | 画面里管子**成弯**（通道转向） |
| 白 `white / HAND` | 画面里出现**人的手或脚** |

## 3. 一个需要你确认的事实差异

| | 地面 |
|---|---|
| `05_赛道布局.mp4`（10-01） | **棕色纸板** |
| 01~04 四次实跑（10-10） | **浅色抛光地面**（画面里还能看到黑色胶带条） |

**这两次不是同一次铺设**：布局视频里的赛道铺在纸板上，而 10/10 实跑的地面是抛光面。
所以《赛道布局》描述的形态**是否等于 10/10 实跑的那条赛道，需要你确认**。
（本文件不替你做这个判断。）

## 4. 看不出 / 无法确认（诚实边界）

1. **管子直径、通道宽度**：视频没有标尺参照，画面又是手持透视，**无法测量**。
2. **弯道半径**：同上，**无法测量**。我只描述"看起来是 U 形/S 形"。
3. **锥桶尺寸**：无法测量。
4. **前轮实际转角**：车在画面里太小、且多为俯视/后视，**看不清前轮偏转**。
   所以"舵机没有摆动"这句是**用户观察**，我无法从画面证实或否证。
5. **撞击瞬间的接触点**：能看到"车头抵在管壁上"，但看不清是哪个角先碰到。
6. **车的绝对轨迹/速度**：摄像机是手持移动的，**无法还原**。
7. **视频时间与遥测时间的对应**：本文件**没有做对齐**（按"不要过度解析"的要求）。
   注：`调试视频` 里没有与这四次实跑对应的 `v2_1010_1803xx/1815xx/1819xx/1820xx` 遥测文件
   （`上位机\log` 下目前只有 `run_1010_171850` 和 `run_1010_175052` 两个 10/10 的采集）。

## 5. 复现命令

```powershell
$py='D:\anaconda3\anaconda3\python.exe'
$R='D:\OneDrive\Desktop\robocup\调试视频\视频解析_AI可读_20261010'
& $py -B "$R\extract.py"   # 抽帧 + 概览联络表
& $py -B "$R\mark.py"      # 生成 overview_marked.jpg（标记色框）
```

**踩过的坑（写下来免得再犯）**：Windows 下 `cv2.imread` / `cv2.imwrite` 对**中文路径会失败**
（`imread` 返回 `None`、`imwrite` 静默返回 `False`）。本目录脚本一律用
`cv2.imdecode(np.fromfile(...))` 读、`cv2.imencode(...)[1].tofile(...)` 写。
