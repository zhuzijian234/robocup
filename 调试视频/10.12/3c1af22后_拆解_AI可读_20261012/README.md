| T04 | 略微勉强,偏移位置可调整 | 4.53 s | +0.45 | +2.50 | **2.05 s** | 137/137 | 19% |
| T05 | 重点排查,对弯道反应太慢,直接撞向赛道 | 3.86 s | +0.41 | +2.10 | **1.70 s** | 117/117 | 16% |
| T06 | 偏移位置可调整,过弯比较勉强 | 4.20 s | +0.42 | +2.55 | **2.13 s** | 127/127 | 18% |
| T07 | 略微刮蹭赛道,偏移位置可调整,左弯整体表现不如右弯 | 4.50 s | +0.41 | +2.94 | **2.53 s** | 134/136 | 21% |

**所以本批对齐不确定度是 1.70~4.24 s**，远大于"成功过弯"那批（0.00~0.95 s）。
我原先的机制假设是"撞车后电机仍转、编码器运动延续到视频结束之后"，**数据只部分支持**：
视频结束后的样本里只有 **16%~44%** 仍 `|speed|>1`，不是全部。**因此这批对齐精度只有秒级，不要再往细里用。**

> ⚠️ 规律（事实）：**成功的批次两锚点差极小（0.00~0.95 s），带撞击的批次差大（1.7~4.3 s）**。

## 5. 参考距离：能给什么、不能给什么

### 5.1 能给的（全部标注口径）
**(a) 固件自己的两个决策距离**（文档 §1，是阈值不是测量值）：
**700 mm**（可见弯墙特征进入此范围 → 转主弯）、**950 mm**（以上采用准备目标，950→700 逐步接回）。

**(b) `acute_feature_y_mm` 的唯一有效采样**：**T02 t=6.12s = 980 mm**
（口径：可见弯墙偏离近切线处；**不是**真实弯口距离；此值 980 > 950，属"完全准备区"）

**(c) `acute_position_mm` 的唯一有效采样**：**T02 = −35 mm**（前轴处，向弯外为负）
**(d) `acute_goal_mm`**：**T02 = 40.0 mm**（上限值）

### 5.2 我独立量的「可见弯墙偏离近切线处」（点云法，8 快照/段）
方法：取该侧 y∈[100,600] 的点自算最小二乘直线，再从 y=600 往上找**第一个偏离 >150 mm** 的点。
**口径同 §3 的警告：这是"墙偏离近切线处"，不是真实弯口距离**；我的阈值 150 mm 与固件 `acute_wall()` 的
"连续 3 个分区偏离近切线 ≥40 mm"不同，**数值不会与 `acute_feature_y_mm` 逐位一致**。

| 段 | 转弯 | 左壁偏离处 y（mm） | 右壁偏离处 y（mm） |
|---|---|---|---|
| T01 | 左 | **669 / 681 / 665 / 669** | —（无偏离） |
| T02 | 左 | **1012 / 915 / 823 / 755** | **921 / 888** |
| T03 | 右 | **763 / 765 / 632** | **857 / 786 / 714 / 629** |
| T04 | 右 | — | **690 / 616 / 722 / 659** |
| T05 | 右 | **788 / 739 / 643** | **1017 / 927 / 806 / 712 / 606 / 605 / 602 / 602** |
| T06 | 右 | **610** | **665 / 637** |
| T07 | 左 | **846 / 802 / 731 / 670** | — |

**读数（事实）**
- 数值随快照推进**单调递减**（如 T01 669→669、T05 左 788→643、T07 846→670、T02 左 1012→755）→ 车在接近该特征 ✓
- 同一段内**左右两壁都出现"偏离处"**（T02/T03/T05/T06）
- **T05（"直接撞向赛道"）** 右壁斜率 `a` 从 0.159 一路涨到 **2.124**（近乎横向），偏离处稳定在 **602~606 mm** → 该段存在一面几乎垂直前进方向的墙 ✓
- 阶段 1/2 的**有效** `acute_position_mm` 只有 1 个采样（T02 = −35 mm），其余采样都在阶段 0，**按文档不得解释为零值/居中** ✗

### 5.3 不能给的
- **前轴到弯口的真实距离**：固件没有这个量，文档也明确说 `acute_feature_y_mm` 与 `turn_distance_mm` 都不是。
- **拟合直线交点法**：作者明确禁止（§2），已撤回。
- **视频里量绝对距离**：手持 + 运动模糊 + 无同深度标尺（与上一批同样的问题），不给。
