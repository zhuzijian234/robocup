## 行为变化

- 模式切换首帧重置D历史，消除前墙/侧墙/中线误差互相相减产生的假回正；同模式的D仍保留。
- 同向大弯降级到较弱转角、或断点暂时消失时，最多延续最后一次有依据的转弯指令350ms。HOLD不刷新期限。
- 无断点且中线至少8点、模式0/5、误差绝对值不超过100mm，连续两帧才提前确认出弯；无效帧打断确认序列。
- 有效反向转弯或更强的同向转角立即接管。每控制帧完成仲裁后只写一次舵机。
- 无效候选不写舵机、不重置雷达看门狗；旧的固定两帧强制打满由有界状态替代。
- 近水平中线不能计算有效PD时标为INVALID，不再无限HOLD并重置看门狗。
- 550/600mm阈值、目标速度10、全部PID增益未改变；不包含提前入弯或增大kp2。
