对照旧成功手推 SUC01–SUC06 的全部 overview：成功样本在明显主转弯开始前已经处于可用的入口横向位置，转弯过程仍要持续保持向弯内转向；这支持“准备应发生在入口之前”的方向，但不能由手推成功证明高速下相同轨迹稳定。SUC01/02 左弯入口可明显见车体靠右侧外边界，但没有同深度标尺，不能从图反推出应加多少毫米。SUC03/04/05/06 俯视角度不同，不能横向比较像素间隙大小。

建议仅作为代码方案的视觉约束：

1. 优先查入口识别是否连续、布位是否在入弯前生效，不据“左弯略差”立即加单侧 Kp 或强制偏置。
2. 允许小幅增大外侧目标，但保持通道余量限制，且不能靠延后正常主转弯来腾出布位时间。T05 是明确反例。
3. 保留 T03 的原有主弯行为作为回归参照，并把 T01/T02/T07 的晚段外前轮接触与 T05 的早期顶墙分开处理。
4. 与遥测关联需由主任务使用原 BIN 时间轴及用户“基本同时开始”的软锚核实，不能使用原 README 的 offset_A 强行逐帧对应。
