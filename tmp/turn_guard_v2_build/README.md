# 弯道修正第二版

固件：robocup_turn_guard_v2.hex；版本：sha256-60ef925c84403520。

## 修改

1. 中位附近（目标方向偏移小于20 PWM）或方向矛盾的候选不能建立或更新弯道锚点。同向旧锚点未超时则延续；到350ms释放，不能由弱候选无限续期。
2. 同模式一次收舵超过60 PWM，也需要出弯确认或原期限到达。左右换向、连续两帧有效直道退出机制保留。
3. 入弯、换向、升级弯道模式时，在P指向正确弯向的前提下增加min(75, abs(P))的同向补偿；同模式后续帧、降级、无效后同模式恢复不重复叠加。总输出仍限于1170..1720。
4. 跨模式D仍重置；持续增益、入弯距离、目标速度未改。

DETAIL保留真实P和D；补偿可以由pwm_unclamped - pwm_mid - pd_p - pd_d复算。HOLD帧中候选PD不标记为已执行。

## 验证

生产C真实PD+状态组合复现左转误差284.289 -> -49.897：首次候选1632，随后1445候选不再覆盖锚点；输出仍为1632，受350ms时限约束。
大左转误差500首帧1720，后续计算值1645；连续弱化候选最多由状态延续350ms后释放，不把75不断累加。
小左转误差83.583入弯1511；矛盾误差-50不加补偿。右转有对称验证。
