## 核心发现：实际为可变帧长

文档常规示例是 160 字节 / 70 个测距槽，实机捕获如下：

| 帧长 | 测距槽数 `(长度 - 20) / 2` | 帧数 |
| --- | --- | --- |
| 156 | 68 | 2 |
| 158 | 69 | 2341 |
| 160 | 70 | 1964 |
| 162 | 71 | 4 |

布局：2 字节帧头 A5 5A、2 字节大端总长度、2 字节起始角、2 字节转速计数、可变数量的双字节测距值、10 字节保留时间区、2 字节帧尾 FA FB。
距离最高位为高反标志；FFFF 先剔除，再按剩余点数 m 使用 `start_angle + 15/m * index` 插值。转速 rpm = 2500000 / speed。

用户专门追问“非 160 字节的包是否是错误数据”。为此已独立检查原始文件（没有依赖自检程序的 Parser）：

- 4311 个连续包的长度字段与实际帧尾位置全部一致。
- 4310 处内部包边界全部紧邻：上一包末尾 FA FB 后立即是下一包 A5 5A，没有内部空隙。
- 4310 次相邻起始角增量全部恰好为 1500（0.01°），即 15°。
- 少见的 156、162 字节帧，其转速和距离未见明显异常。
- 162 字节示例：原始偏移 143909，头 `A5 5A 00 A2 7E 2C 0D 9F`；角度 308° → 323° → 338°；包尾接下一帧 `FA FB A5 5A 00 9E`；前六点距离 513、514、504、501、500、502 mm。
- 156 字节示例：偏移 295871；角度 248° → 263° → 278°；长度字段 00 9C；帧尾正确且紧接下一帧。

结论边界：有很强的证据支持这些是结构完整、连续的正常变长帧，不能仅因不是 160 字节就丢弃。协议没有校验和，不能保证每个字节均正确。具体为什么变长、厂家正式支持的长度范围，资料未明确说明。采样与电机区间边界不同步、细微转速波动是合理推测，不能当作已经证实的固件机制。

## 当前 STM32 接收代码不兼容

工程：`2-LXY传承/LXY传承-m10p`。
已实际检查：

- `HARDWARE/LEIDA_DATA/m10p_config.h:11`：`M10P_PACKET_BYTES` 固定 160。
- `HARDWARE/LEIDA_DATA/m10p.c:56`：组包缓冲只有 160 字节。
- `m10p.c:315`：长度字段不等于 160 就判 bad_length。
- `m10p.c:318`：固定凑满 160 字节。
- `m10p.c:321`：帧尾固定读取 packet[158]、packet[159]。
- `m10p.c:262、263、268、269`：解码循环和空槽统计固定 70。
- `HARDWARE/hc-05/ble_diag.c:477`：诊断说明也固定宣称 160B/70slots。
- `USER/main.c:115` 使用 `uart2_init(M10P_BAUD)`，512000 波特率与实机一致。

本次数据有 2347/4311（约 54.4%）的包不是 160 字节。现有 STM32 代码会拒绝它们，并因 abandon() 反复丢弃在拼接的扫描圈。Python 的 PASS 不代表 STM32 已兼容。

## 重构时应处理并验证

1. 区分组包缓冲容量上限与当前包的实际长度；合法长度检查仍需有界，不能无限等待或越界。
2. 根据双字节长度字段组包，在实际长度末尾检查 FA FB。
3. 测距槽数按 `(length - 20) / 2` 计算，替换所有固定 70 的解码与统计。
4. 保留现有错误重同步、角度连续性、扫描完整性、转速与时效保护；不能只放宽长度判断。
5. 检查短帧、长帧、坏长度、分片/连续帧、FFFF、高反、跨零点及缓冲边界。
6. 将已保存的实机 `.bin` 回放到实际 C 解析器，验证点数、角度、帧统计和整圈发布；回放时间戳需模拟真实字节/DMA 到达时间，否则现有周期门槛会错误拒绝。
7. 运行工程原有相关回归和构建检查，再做 STM32 板上 USART/DMA 联调。完整兼容的结论必须有对应验证。

Python 当前接受 22–512 字节的偶数长度，该上限只是主机工具的防御性边界，不是厂家确认的协议最大值，不能未经容量评估直接照搬至固件。

## 接线背景

用户描述转接模块从上到下标注为 5V、GND、TX、RX、NO、NO。
模块自身 TX 一般接雷达 RX，模块 RX 接雷达 TX；配套线目前实测可用，不需改线。
手册雷达信号名为 VCC、GND、RX、TX、PPS、REC；后两者用于 GPS。
不能凭转接板的两个 NO 推断雷达插头的实际脚序或映射。雷达供电 5V，串口为 3.3V TTL。
